紀景一路走出陸斯年臥室， 陸斯年的家裡可以說是一團狼藉，扯掉的襯衫和凌亂的領帶就胡亂扔在地上， 每看一眼都能讓記憶中的畫面更加清楚。

他找到自己皺巴巴的衣服往頭上一套， 快步離開了陸斯年的家。

終端被開啟，未讀的訊息一窩蜂的闖入紀景的視野。

大多是都是學校發來的，問他為什麽又連續好幾天無緣無故不去上課， 其中還參雜著老爸老媽和紀芸希的未接電話。

【紀芸希】：你怎又曠課了

【紀芸希】：又不接電話？不會又在陸斯年家裡吧！

【紀芸希】：爸媽那我給你穩住了，搞快點！

…

紀景坐在回家的車上， 後知後覺地感覺到太陽穴脹痛。

除了太陽穴外，他後頸的alpha腺體也酸酸脹脹的，他隨手摸了一把， 才發現上面還有凹凸不平的牙印…

是陸斯年咬的。

為什麽要咬呢，是生氣，還是情至濃處把他當成易南了。

嘖。

紀景很煩， 尤其是想到剛才發生的種種。

就這樣吧， 斷了就斷了，反正陸斯年也恨死他了，他憤憤的想。

按照紀景對陸斯年的了解，他認為當時陸斯年留下來估計是因為自己替他擋了那一針心裡過意不去。

以陸斯年那古怪的責任心，扔下他跑了才不正常。

至於後來…那應該是陸斯年沒有抵抗住他alpha的信息素， 所以才跟他稀裡糊塗的上了床。

紀景對陸斯年的行為做出了冰冷無情的解釋。

他其實從一出來就後悔了，後悔剛才對陸斯年說的那番話。

紀景從小就是一個很要強的人，他忍受不了任何人指責， 也忍受不了任何失敗。

所以他才會在當初被追求的omega拒絕後對陸斯年惱羞成怒，被劇情靈魂趁虛而入。

所以他才會在陸斯年戳穿他， 意識到自己偽裝失敗， 或者是感情上真實的身份不被陸斯年認可後沒有控制住自己的情緒。

最後他其實有很多話想說， 但在看到陸斯年眼眶裡的紅血絲後，只能化為一聲對不起。

終端的震動打斷了紀景的思緒，是王鵬發來的消息。

【王鵬】：你小子又給我搞失蹤！

【王鵬】：今天周五了，下午五點第三軍團征兵就結束了，你還來不來啊。

【王鵬】：要來的話現在趕來還來得及，機不可失啊紀景。

今天周五了，意味著他在陸斯年家裡呆了整整三天。

紀景垂眸注視著這段文字，恍然若聞，剛想打字，卻在手指動下的一瞬間輕聲笑了出來。

他竟然在這個時候也在想陸斯年，想他如果不去報這個名，他和陸斯年是不是就徹底分道揚鑣，幾百年見不上面了。

就算去了同一個軍團又如何呢？

陸斯年根本不想看見他吧。

於是紀景放平了嘴角，回復

【紀景】：不去。

車停在了紀家莊園門口，紀景下車，一路往家裡走。

這個時間紀父紀母都不在家，但紀芸希活像個守門人一樣，在他剛回家時就把他堵了個正著。

“老實交代，這幾天你又幹嘛去了，是不是和陸斯年在一起！”

紀芸希叉著腰，指指點點，擠眉弄眼，“幹啥啊，不是說要跟他分手嗎，怎麽還成天膩歪在一起…”

“分了。”

紀景面無表情地打斷了紀芸希八卦的語氣。

“…啊？”

紀景沒理傻在原地的紀芸希，抬步上樓。

然而這時紀芸希在他身後驚呼了一聲，“天呐！紀景你腺體那兒是怎麽回事兒！”

紀景停下，下意識摸了摸後頸，猶豫了半響，隱瞞道：“沒什麽。”

目前的情況還不允許他把全部事情說出來，但紀芸希接下來的話卻讓他想起來什麽。

“我看你腺體的樣子怎麽像是alpha來易感期的時候，你注意點啊，萬一你突然來易感期怎麽辦，上面不會是陸斯年咬的吧，呼，幸好他只是個beta，不然…”

“alpha對omega的標記多長時間能消除？”

紀景突然問道。

紀芸希一愣，“普通標記都挺快的，最多一個月就沒有了，怎麽了嗎？”

“沒什麽。”

那陸斯年頂多一個月就跟他徹底沒關系了。

…

【王鵬】：陸總指，紀景他沒去報名第三軍團的征兵。

【王鵬】：你能不能跟周渡說說，真不怪我啊，我都勸得口乾舌燥了，這小子不願意我也沒辦法。

陸斯年站在空蕩的客廳中央，看到了王鵬發來的消息。

他花了幾天時間辦完了帝國軍校離職手續、回軍團前需要的所有的手續、以及團長繼任申請。

他的行李很少，少到只花了一個小時就將整個屋子的東西收拾好了。

腳邊放著一個簡單的軍用行李包，後天一早只需要一提就能離開這個屋子，不留任何存在的痕跡。

【陸斯年】：好的，我知道了。

陸斯年並不意外這個結果。

這幾天他甚至想過，如果當時他假裝沒聽見紀景用女聲，那麽紀景是不是就不會逃跑。

【陸斯年】：接下來一年辛苦你好好帶紀——

還沒等他發出去，張邈的電話打了進來。

“你的舉報信交到我這裡了，林延山的事你確定要上訴嗎？”

“確定。”

“你要想清楚，如果上訴，你omega的身份就必須曝光在全帝國面前。”

“我接受。”陸斯年平淡地說。

“嗐。”張邈重重地歎了口氣，“成吧，但是我話說在前面，你能接受不代表第三軍團的Alpha能接受。還有就是，裡面有一點不對啊，你說你被林延山打了加敏劑，那你後來怎麽解決的？”

“這不重要，林延山他會承認。”

陸斯年沉寂的黑眸裡亮起了一道寒光。

“陸斯年，我真沒想到你會為了我甘心曝光你omega的身份，為什麽要我隱瞞紀太子的事，對你有什麽好處嗎？”記憶裡林延山氣若遊絲地猖狂冷笑。

“你只需要明白，如果讓紀家知道你對紀景動了手，你會死的更慘。”陸斯年踩著他的胸口，低聲道。

林延山當時臉色又青又白，最後突然嘲諷的笑了，“得了吧，你當我真不知道你就是為了給他報仇，不然你這麽能忍的人，怎麽可能做到這個地步，陸斯年，真沒想到你竟然會為了一個alpha…”

…

掛掉電話後，陸斯年不由自主地點開了一個聊天框。

對面的人頭像已經灰掉了，留下來的只是一片死寂。

不知道看了多久，陸斯年才緩緩地合上了終端。

…

“紀景。”

手指叩擊桌面的響聲冷不丁地拉回了紀景澎湃的心緒。

“你這幾天怎麽回事，爸爸媽媽給你說話你老是走神。”

飯桌上，紀父嚴肅地看著他道。

紀芸希見狀連忙來調解氣氛，“嗨呀，肯定是老爸你說陸斯年是個omega的消息把他嚇了一大跳，紀景你說是不是？”

紀芸希一邊說，一邊用手肘推搡紀景。

今天吃早飯的時候，紀父按往常一樣打開了早間新聞，一邊看一邊說起了陸斯年起訴第三軍團現任總指林延山的事，還打開了終端給他們看新聞。

“啊，對。”紀景恍惚應道，他還沒從這件事裡緩過神來。

陸斯年以自爆自己是omega為代價起訴林延山，他瘋了嗎？

為什麽這麽做，他不是最在意自己變成omega了嗎？

紀景知道陸斯年的禁忌就是omega的身份，所以自從回來後他從未提過自己被打了加敏劑導致易感期初次來臨的事，因為一旦告訴紀父紀母，陸斯年是omega的事就會因為林延山被迫曝光。

而且為什麽這件事自始自終都沒有提到他。

紀景突然想到了一個不可能的猜想——難道陸斯年是為了不把他牽扯進去。

“陸斯年不該說出來的，軍團並不要求軍人曝光性別，他已經接任了第三軍團的團長職位，不管是軍團裡的alpha還是帝國的alpha，都會對他omega的身份不服。”

紀父隨口提到。

紀景還在震驚之余發神，王鵬的消息就發了過來。

【王鵬】：有個人讓我轉告你，讓你記得去醫院看看。

很莫名其妙的一條短信，但紀景一下子就明白過來那個人是誰。

是陸斯年，陸斯年讓他去醫院。

紀景咬緊牙關，反手摸了摸仍然有些發腫的腺體，一言不發，他確實應該去醫院看看。

吃完早飯後，紀景就出門了醫院。

初次易感期可謂是alpha最重要的時期，一不留神就是終身殘廢，紀景這麽多天沒當回事兒，醫院裡的老頭alpha跟看傻逼似的看他。

尤其是聽到紀景說自己是被信息素加敏劑引起的初次易感期後，老頭嚇得手裡的單子都顫了一顫。

“我說你這激素數值怎麽這麽怪呢。”老頭看著手裡的表，強裝鎮定地喝了口茶。

“不過幸好，你家omega處理的及時，不然你就終身殘廢了，目前看你的alpha信息素還算正常。”

紀景拿回單子，等老頭開藥。

“要不然待會兒你再在藥房拿副安胎藥，初期omega是最容易流產的…”

老頭開完藥，一邊說著一邊拿起茶杯喝了一口。

“什麽，誰安胎？我是個alpha。”紀景一愣，轉身看他。

“我當然知道你是個alpha，藥是給你的omega喝的。”老頭嚴肅道，“終身標記後omega受孕的可能性高達90%，你們得隨時注意。”

“什麽終身標記？”紀景晃了晃神，然後慢慢瞪大了眼。

老頭似乎意識到事情的不簡單，放下茶杯鄭重道：“小子，你是信息素加敏劑導致的初次易感期來臨，唯一能幫你度過易感期的只有終身標記omega，換言之，你的omega被你終身標記了，你明白了嗎？”

直到從醫院走出來後，紀景都還處於遊魂狀態。

終身標記。

那老頭說他把陸斯年終身標記了。

老頭說終身標記是要進入生殖腔才能完成，按照他的ao性.科普的知識，他突然想起陸斯年曾主動…

想到這裡，紀景後知後覺意識到，陸斯年原來已經被他終身標記了。
