# QA CLARIFICATIONS — CHƯƠNG 84: HỆ THỐNG (系统)

## BẢNG A: MA TRẬN NHÂN VẬT & ĐẠI TỪ XƯNG HÔ (PRONOUN MATRIX)

| Nhân vật | Ngôi thứ 3 (Narrative) | Xưng hô thoại (Dialogue) | Vai vế & Ngữ cảnh trong chương |
| :--- | :--- | :--- | :--- |
| **Đào Dã** | `cậu / Đào Dã` | Xưng: `tôi / bố mày / ông đây`<br>Gọi: `anh / mày / đồ biến thái / Tuế Dư An` | Công trai thẳng. Bất lực vì cơ thể phản bội trước Tuế Dư An; hăng hái chỉ đạo dự án Tổ công trình chuỗi hải sản; không ngủ được khi thiếu Tuế Dư An; cùng cười lăn lộn khi sập giường; bàng hoàng đau đớn đến nát vụn khi thấy Tuế Dư An bị bắn ngã xuống biển. Tuyệt đối KHÔNG xưng "em". |
| **Tuế Dư An** | `anh / Tuế Dư An / hắn` | Xưng: `tôi`<br>Gọi: `cậu / thỏ con / chủ nhân (trêu đùa)` | Thụ M biến thái. Tinh ranh nhận ra Đào Dã cho phép mình bám riết; hào hứng mua áo khoác mới bằng đồng lương đầu tiên; chạy ùa ra biển và bị tay súng ám sát bắn ngã xuống biển. |
| **Đại tỷ tiện lợi** | `chị / đại tỷ` | Xưng: `chị / tôi`<br>Gọi: `cậu / em` | Đồng nghiệp cùng ca với Tuế Dư An tại cửa hàng tiện lợi 24h, điểm trúng tim đen chuyện Đào Dã bao dung cho Tuế Dư An. |
| **Đội trưởng vệ sĩ / Tay súng** | `đội trưởng / gã / tên kia` | Xưng: `tôi`<br>Gọi: `ông chủ` | Phản bội, bí mật sát hại đồng đội và rút súng khống chế Đào Dã, bắn Tuế Dư An. |
| **Hệ Thống** | `Hệ thống` | Thông báo cơ học trong ngoặc vuông: `【...】` | Xuất hiện cuối chương kích hoạt đội hộ vệ thụ quyền. |
