# 渣男不配洗白 第31章

如果谢辰扬能听到这句话，他会重重地点头，甩他一句，强者为尊。

隗津淡淡道：“若有本事，你要谋朝篡位吗？”

谢辰扬惊诧地看着他：“你怎么会有这种想法？自由自在不好吗？为什么要干这么辛苦的事？”

夏远逸：“……”好的，我明白了。

谢辰扬：“不说这个了，大哥，你准备带多少人马？需要多少兵器？对了，我有魔门分布图……”

十日后，朝廷派了五万兵马，由夏远逸率领，与名刀山庄五百余弟子一同攻入魔门。

其实灭一个魔门，远要不了五万兵马。

夏远逸只是想以此告诉那些江湖人，纵你们武功高强，也敌不过千军万马。

以前没有整顿武林，不过是想先除外患，再解决内忧。

否则武林人反扑，外面还要打架，有些麻烦。

名刀山庄归顺朝廷，朝廷带兵灭了魔门的事一下子在江湖传开。

其他门派的人瞬间不好了，迅速聚集起来议事。

烈阳堡堡主：“老夫当初看到那个禁卫军副统领，就知道名刀山庄铁定要归顺朝廷了！他还想把我们拉下马，简直给武林丢人。”

紫炎府府主：“我觉得是因为我们没有结盟之心，名刀山庄才选择了朝廷。”

“荒谬！江湖事江湖了，他为了报仇归顺朝廷，朝廷因此踏入武林，往后……”

“阿弥陀佛，”佛安寺凌空法师缓缓道，“我们的门派在夏云国境内，我们生在夏云，是夏云之人，那武林也是夏云的武林，本就不该藐视王法。”

烈阳堡堡主：“凌空法师果然是朝廷派来的吗？”

佛安寺方丈：“凌空师弟说的很有道理，我们本就是夏云国子民。”

“佛安寺这是也要归顺朝廷了？”

“施主何必咄咄逼人。”

且不论他们如何争吵，夏远逸把谢辰扬的建议呈了上去，得到了皇帝的应允。

于是，朝廷对武林各门派发了文书。

认自己是夏云国子民，便按夏云国法行事。

不认自己是夏云国子民，便离开夏云国，否则将会出兵强制将其驱除夏云国境。

谢辰扬原话是：想当夏云国的人就听话，不想的就滚出去，到别的国家去浪。

当有个门派表示死也不会归顺朝廷，意图煽风点火，带动大家一起反抗朝廷时，夏远逸带着军队将那个门派的人都抓起来，丢出了夏云国。

紫炎府第一个表示她们是夏云国人，愿遵守国法。

陆陆续续地，其他门派纷纷都“归顺”了朝廷。

谢辰扬听到这件事之后毫不客气地嘲笑了一番。

朝廷倒也没有为难武林门派。

只是他们不能再向以往一样肆无忌惮的宣称江湖事江湖了。

若有人犯事，一样要扭送官府，不得以武林人的身份包庇其罪。

只要不触犯国法，他们想做什么就做什么，并且，要交税。

不能其他国民都要交税，就你武林人不交。

而名刀山庄，还是一如既往。

只不过以前给各大门派供应武器，现在多了个朝廷。

那五百个侍卫没有走，还是作为名刀山庄的弟子待在山庄里，学习铸造。

隗津依旧每日练剑，只他练剑时，身边多了个练刀的谢辰扬。

年复一年。

当凌弈能独当一面后，谢辰扬表示要把庄主之位传给他。

凌弈立刻拒绝。

谢辰扬皱眉：“你知道我和阿津的关系，我肯定不会娶妻生子的，反正也后继无人，你是我父亲的徒弟，是我的师弟，山庄由你来接任最好不过。”

凌弈涨红了脸：“庄主，我有负你的期望……我也不娶妻生子。”

谢辰扬：“啊？你……不行？”

凌弈咬牙道：“我很行！我只是与庄主一样，好龙阳！”

谢辰扬：“谁啊？”

凌弈没有回答，只是道：“若庄主想要继承人，我倒是有个人选推荐。”

“他原本是铸刀长老的弟子，喜爱铸造也喜爱刀法，所以不管是铸刀还是舞刀，他都很擅长，且人缘极好，行事周全……”

“行，那就传给他。”

凌弈自以为打岔成功，去找未来的庄主透露消息去了。

他走后，谢辰扬朝隗津挤了挤眼：“走，我们跟去看看，凌弈这小子，到底和谁在一起了。”

隗津：“很好奇？”

“好奇啊，”谢辰扬轻哼了一声，“把我看好的继承人骗走了，我不得看看对方是何方神圣？”

隗津淡淡道：“是我好友。”

“你好友？”

隗津的好友屈指可数。

“那个和尚？”

“嗯。还好奇吗？”

“算了算了。”

谢辰扬见过了凌弈说的那个人，在系统说好，隗津也说不错之后，干脆地把庄主之位交给了他。

第二天就带着隗津跑了。

系统：“那个……魏文彬……”

【他还没死？】

系统：“还没呢，被关在山庄地牢里，生不如死。”

【哦，无所谓，放心，我死也不原谅，任务肯定能完成】

系统：“对你，我当然放心。”虽然和它想的不太一样，但他肯定能完成任务是真的。

谢辰扬牵着隗津的手，深情道：“知道我要带你去哪儿吗？”

隗津：“去哪儿？”

“天涯海角。”谢辰扬双眼带着散不去的温情，“我要让这天下的每个角落都沾上我们爱的味道。”

【这情话给几分？】

系统：“……”不想打分。

谢辰扬和隗津当真形影不离地开始游山玩水，玩尽了各种花样，直到白发苍苍了才回了京都。

隗津：“我以为你要回名刀山庄。”

谢辰扬：“名刀山庄早就更新换代啦，我们这些年都是隔个一两年才来看看你的亲人，现在都快死啦，回来让大哥帮我们收尸吧。”

隗津：“……”我大哥也快死了。

他无奈地和他一起去了将军府。

自长公主去世后，隗津的大哥和三弟就分了府。

夏远逸虽然不是将军了，但他的儿子是。

所以将军府的牌匾一直没有换过。

知道他们俩来了，原本躺在床上奄奄一息的夏远逸突然精神起来了。

然后第二天就去世了。

谢辰扬压低声音：“没想到大哥真的比我们先走，要不，我们去找弟弟给我们收尸？”

隗津很是无语。

要他说，他们直接找个无人的地方死了便是，何必要回来劳累亲人来着。

跟在他们身后的少女听到了谢辰扬的话，瞪圆了眼睛：“二爷爷二奶奶不要怕，会给你们收尸的！”

夏远逸长子听到女儿这么一喊，在看两位挨得极近的老人时，心中的悲伤散了些许，郑重道：“二叔，阳叔，就在府中住下吧，一切有侄儿呢。”

谢辰扬：“好哦。”

说是等着收尸，实际上他们还多活了一年，每天就逗逗将军府上的小辈。

等到隗津去了，谢辰扬才收了心。

【走吧，去下个世界继续和我的爱人缠绵】

系统：“……恕我直言，下个世界他根本不认得你。”
