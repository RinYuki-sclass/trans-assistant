# 渣男不配洗白 第72章

“我找到了合适的材料，我们走吧。”

谭荣收起图纸，率先站起身：“但是，晨哥，这升降梯要建好，上下皆需安排，我们上下一次需要那么长时间，得多久才能建好啊？”

山下。

范温泽他们没有特意驻扎，而是宿在了马车里。

艳阳高照。

他们出来活动身子。

严棋和解玉秋站在一起，看着换上男装的范温泽，小声道：“原来范大人是男儿身啊。”

解玉秋：“嗯。”

“那范夫郎……喻晨哥和范大人，是假的吗？”

“你怎么知道的呀？”

解玉秋温声道：“自然是看出来的。”

严棋十分震惊：“可是，男子和男子……他们胆子好大呀。”

解玉秋笑了：“若是胆子不大，又怎会占山为王，又怎会想要开辟新国。”

严棋：“可是……”

严棋话没说完，就被言月的惊呼声打断了。

言月：“大人，上面掉下一根……藤蔓？”

范温泽眯眼上前。

言月眼尖道：“有人顺着绳子下来了。”

很快，谢辰扬顺着藤蔓落地。

他手上戴着一只黑金手套，松开藤蔓，上前就抱住了范温泽。

范温泽身子一僵。

幽篁：“松手，你身体太凉了。”

谢辰扬尴尬地松开手：“没事吧？我迎风而下，身子有些凉，山上还下雪了呢。”

不过他身上的雪花都被风给吹没了。

范温泽：“无事，这是？”

“不是说了要做升降梯吗？”

谢辰扬上前扯住藤蔓，颇有节奏地拉扯了三下。

很快，藤蔓被山顶上的人拉了上去。

谢辰扬道：“他们在上面，我们在下面，一起完成。”

范温泽：“你说的升降梯究竟是何物？”

“一种机关吧，做好了你就知道了。”

在谭荣他们把材料放下来之前，谢辰扬也没闲着。

他写了两张名单，一张交给解玉秋：

“这张名单上的人是曜国边城外几个村子的人，上面有备注村名，你去游说，把他们带来。”

解玉秋收下名单：“定不负公子所托。”

谢辰扬：“言月，你带一个人一起跟着解玉秋，保护好他。”

言月停顿了一会儿，没听到范温泽的反对，才领命：“是。”

他们带着一辆马车走了。

谢辰扬拿出另一张名单。

严棋眼巴巴地看着他。

谢辰扬有些迟疑。

之所以交给解玉秋，是因为他足智多谋，知识渊博，又有言月他们保护，安全系数比较高。

但严棋……

严棋感觉到他的犹豫，上前道：“喻晨哥，我也可以的。你要邀请的人是男子吧？我也同是男子，以身现说法，我不会搞砸的。”

谢辰扬看向了严父。

解玉秋孤身一人，但严棋可是有父亲在的。他父亲未必放心他。

严父长得柔弱，面带担忧，但还是道：“喻公子就让他去吧。”

谢辰扬把名单交给了严棋，看着他眼中的亮光：“注意安全。”

严棋重重点头。

谢辰扬看向了剩下的两个护卫：“这名单上的人是蓝州城与曾经的寂国边城之间的几个小镇的人，你们俩护着严棋过去。”

范温泽扯下了腰间玉佩：“这是殿下赠我的，上面有曜国皇室标识，若遇到曜国官兵为难，你们便拿出来。”

又一辆马车离开。

之后，藤蔓绑着材料被放下来。

剩下的人帮着谢辰扬打下手，开始制作落点。

耗时几天，期间谢辰扬顺着藤蔓上上下下，在幽篁的指点和暗中帮助下，升降梯终于完成了。

谢辰扬：“我先试一下。”

范温泽看着可容纳十余人的“电梯”，眉头微蹙：“是否成功还不知道，不如先放空梯上去？”

“我有信心，”谢辰扬朝他伸出手，“不如阿泽与我同去？”

幽篁已经肯定了安全系数。

他想要先试一下，主要是安其他人的心。

否则这万米高山，谁不怕摔个粉身碎骨？

范温泽将手放在了他的掌心。

【爸爸，我去了哦】

幽篁：“去吧，我刚才已经用了障眼法，在上下都布了防御阵，电梯内也要防御阵。不会散架，不会坠落，稳得很。”【好咧。你这样说的好像修仙世界啊哈哈哈】

谢辰扬带着范温泽打开电梯门，走了进去，按下了机关。

四条藤蔓固定的电梯在灵石磨成的交叠机关之下直线上升。

严父等人提了一颗心，抬头看着电梯消失在他们的视线里。

电梯里。

谢辰扬也感觉到了范温泽的紧张，伸手抱住他：“别怕。”

范温泽回抱他：“我不怕。”

“你明明很怕。”

范温泽神情紧绷，转移话题：“你怎么知道这里有一座高山？”

谢辰扬：“……”我爸爸说的。

“又如何懂这机关之术，敢于万里高空间设下机关？”

“……”还是我爸爸说的。

谢辰扬踮脚抬头覆上他的唇，趁他双唇微启直接探入，躲避这些他还没编好答案的问题。

第49章 这悲惨的小夫郎（十一）

万米高空没那么快就到。

谢辰扬和范温泽在升降梯里享受了一个绵长的吻。

当升降梯停下, 谢辰扬松开范温泽，伸手擦了擦他的嘴，舔舔唇按下了开门机关。

升降梯停留的位置与山巅几乎持平, 轻轻一跃就能过去。

谢辰扬带着范温泽走过去, 对谭荣道：“你下去把他们接上来吧。”

谭荣：“好的。”

山上的雪已经停了。

地上覆盖着一层浅浅的白。

范温泽跟他一起往中间走去，轻声道：“有了升降梯，生活上会方便很多，但若升降梯被人毁了……”

“没有人能毁。”谢辰扬回答得十分肯定。

毕竟，爸爸可是动用了防御阵啊。

范温泽不知道他的自信从何而来，但他既然肯定, 他就没有再猜疑。

他发觉，他这心爱之人太过神秘。不像是普通知府能养出来的孩子。

谭荣下去接人，谢辰扬他们几个就砍了竹子临时搭起了几间木屋。

谢辰扬：“等解玉秋他们带来新人, 我们就有人手了，现在先将就着。”

没有人有异议。

谭小弟乐道：“这样隐居的日子也挺好的，山上风景怡人，我到后面看过了，还有一处温泉，林间还有不少飞鸟……”

谢辰扬意味深长地看着他：“谁告诉你, 我们是在此隐居的？”

谭小弟：“啊？不是吗？”
