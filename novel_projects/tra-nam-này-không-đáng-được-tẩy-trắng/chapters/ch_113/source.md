# 渣男不配洗白 第113章

无缘无故，那个已经落魄的世家公子李承望为什么要去杀害他谢辰扬他们一家？

柏庄眼神暗了暗：“玉韬可在？”

管家摇头，顿了顿：“少爷和一些世家公子去骑猎了，李承望也在。”

柏庄：“去把他带回来。”

管家：“是。”

他没叫人，亲自往外走去。

柏母抹了抹泪，凝望着谢辰扬，想说什么，又不知道该如何开口。

谢辰扬：“我们一路赶来，有些累了，母亲能给我们准备房间休息吗？”

柏母连忙点头：“当然，我这就让人去准备。”

下人领着谢辰扬他们去休息之后，柏庄派他的亲卫去查柏玉韬和李承望的关系。

亲卫知道这事不能拖，立刻调动人脉去查。

柏玉韬和李承望谋划的时候十分自信，并没有过多掩藏。

柏玉韬已经想好了。

李承望就算没能完成任务，他派去的人也能把杨洲他们都杀了。

而他不看身份，只看才学，结识了李承望，也并不奇怪。

所以，亲卫没费多少力气，就查出了在李承望去边城之前，柏玉韬曾见过他，还给了他一笔钱。李承望回来之后，柏玉韬就带他去结识其他世家公子了。

这一下，不用再怀疑。

李家与边城毫无干系，李承望没事怎么会去边城？还有目的的结识杨洲，诱他出海，然后将他丢入海中。

只能是柏玉韬。

只会是柏玉韬。

说是休息，但谢辰扬和艾修回房后并没有睡觉。

艾修：“那个人长得好像你啊，他就是你父亲吗？”

“嗯。”名义上的父亲。

艾修：“刚才的话我大概听懂了一些，我们捡到你的时候，你是被人丢在海里的？”

“那我是你的救命恩人了。”

谢辰扬把他搂入怀里，轻笑道：“所以，你的救命之恩，我就以身相许了。”

艾修也跟着笑：“那我是不是可以把你带回家了啊？”

“是啊，”谢辰扬轻揉着他的唇瓣，“从此以后，你在哪儿，我便跟到哪儿。”

艾修觉得不对：“现在明明是我跟着你啊。”

他本该跟着臣下们去大云国都城的。

但被谢辰扬给哄到这怡州城来了。

谢辰扬低头亲了亲他的唇：“这次你跟我，往后余生都是我跟你。”

“唔。”艾修含糊地点头。

这样算起来很划算。

他要把谢辰扬带回去，当他的王妃！

柏母镇定了许多。

她心中思绪万千，对谢辰扬想要亲近又怕他不喜。

此时以为他休息了，悄悄地走到他门外，带着踌躇又忐忑的心情。

若他没睡，她就和他母子俩好好聊聊。

若睡了，那她便等他醒来再聊。

柏母深吸一口气，抬手刚要敲门，就听到里面传来一声闷哼。

随之而来的，是谢辰扬的低笑声和小王子的低喘求饶声。

柏母：在打闹？

她又听了一会儿，红着脸后退。

出了院子后，她脸上的红晕消退，随之而来的是担忧。

世家子中，男子与男子之间的感情倒也不少见。

但那到底只是玩乐。

和谢辰扬在一起的那人，一看便知是异域男子。

不知道到底是他玩他，还是他玩他？

亲卫把调查消息带回来的时候，柏玉韬还没回来。

柏庄和柏母一起听着亲卫的汇报，他们的脸色都不太好看。

若说对柏玉韬没有感情，那是假的。

他们毕竟将人捧在手心上疼了那么多年。

但一想到他不知何时知道了身份的真相，竟不告知他们，还悄悄派人去将他们的亲生子灭口，意图灭人全家。

简直丧心病狂。

对他，他们就心疼不起来了。

柏母紧抓住扶手：“若不是那异域的船救了洲儿，我们怕是至死都不会知道真相了。”

柏庄：“不管洲儿想要如何处理，我们都不能插手，更不能为……他求情。”

柏母闭上眼：“我知道。”

晚膳摆上，柏庄和柏母也没有摆架子，让谢辰扬他们一行四人都同桌用膳。

谢辰扬主动提起：“父亲和母亲要如何处置柏玉韬？”

柏庄面色严肃：“若真是他害你和你养父养母的性命，那此事我们不插手，你想如何就如何。”

谢辰扬：“可他是柏家之子，我如何与他抗衡？”

“他不是，”柏庄答得很果断，“你才是。”

其实他已经心知肚明，害了杨家一家的，柏玉韬就是罪魁祸首。

谢辰扬这才笑了：“多谢父亲。”

看到与他长得这么相似的孩子叫他父亲，柏庄心中慰烫：“待他归来，我会宣布将他逐出家门，将你纳入族谱，从此你才是我柏家子。”

这样一来，柏玉韬就没有了柏家的资源，毫无反抗之力。

而他最为看重的，就是柏家子的身份。

谢辰扬将他最为看重的给他剥去，先杀李承望，再诛柏玉韬。

此时，门外传来一个声音。

“老爷夫人，少爷回来了。”

第76章 这悲惨的真少爷（七）

管家派人去找柏玉韬的时候, 并没有告诉他家里发生的事。

而世家公子们是他起的头，自然不会还没开场就离开。所以他过了好久，直到结束才跟着管家回家了。

他看管家安静地等了那么久, 以为不是什么大事。

但当进入客厅, 看到那长得与柏庄一模一样的谢辰扬时, 前世被赶出家门的一幕仿佛出现在他眼前。

他的脸色倏然变白，此时脑海中只盘旋着一个念头。

完了。

谢辰扬微微一笑：“我没有死, 你是不是很失望？”

柏玉韬的设想中他是没可能活着回来的, 所以和李承望之间的交涉并没有做什么掩藏。

他知道这事根本不经查。

前世仅仅是引得杨洲不喜，他就被赶出了家门。这次他还下了杀手……

柏玉韬回过神，立刻想要转身往外跑。

守在门外的护卫拦住了他。

就他那做贼心虚的要跑的模样, 柏父柏母无需再问。

谢辰扬站起身, 一步一步走到了门口被护卫压制着的柏玉韬面前，微微倾身, 低声道：“杀人偿命, 你死定了。”

柏玉韬瞳孔一缩。

谢辰扬后退一步：“那就把他从家谱除名, 逐出家门, 并将他的所作所为公布出去。父亲, 母亲, 你们没有意见吧？”

柏父和柏母自然是没有意见的。

柏玉韬就这样被丢出了家门。

很快, 柏家就将这件事对外宣布了。

艾修不解道：“就这样放过他了？”

要是在他们雷森国, 这种人逃不过一个死刑。

谢辰扬：“当然不会。”
