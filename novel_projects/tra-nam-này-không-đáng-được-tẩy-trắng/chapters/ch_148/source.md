# 渣男不配洗白 第148章

【怎么跟吃了柠檬似的？】

爸爸爸爸叫得好听，他还没吃过他做的饭呢！

时间还早。

谢辰扬掏出手机认认真真搜了食谱，在厨房开始精心操作。

汽修店。

余嶂把男朋友介绍给了严清认识：“他叫唐哲彦，你不看电视或许不知道，但你很多同学肯定认识他，要签名吗？”

唐哲彦无奈道：“别听他的，我不温不火的，没什么名气。”

严清打了招呼，若有似无的观察着他们。

也许是因为他在，唐哲彦和余嶂相处得并不亲密，但不难看出他们很有默契，一个眼神，一个动作，就知道对方在想什么。

严清：“所以，你是他的粉丝？”

唐哲彦侧头微笑：“是吗？你是我的粉丝？”

“当然啊，我们好上那天我就开始粉你了，噗嗤，”余嶂也跟着笑了，不过片刻就收敛了笑意，“说到粉，我前两年倒是粉过一个明星。”

唐哲彦：“哦？前两年？现在有我了，所以爬墙了，不粉了？”

严清对娱乐圈的事情没兴趣，闻言觉得有些无聊。

“不是，他退圈了，”余嶂觉得十分可惜，“你在娱乐圈，就算不认识也应该听过他。”

“沈扬帆。”

余嶂话音一落，严清就抬起了头。

沈扬帆这个名字本来他应该不知道的。

但早上陶小松出门前悄悄跟他说了一句话。

“我舅舅叫沈扬帆，你叫他沈叔叔就好了，他人很好的，你有什么不方便就跟他说，或者给我打发信息，我跟他说。”

沈扬帆。

唐哲彦：“他啊……”

“唉，不说这个了，你……”

“为什么不说？”

严清对上余嶂疑惑的视线，不自在的别过头：“为什么不说？我对你以前的偶像……挺好奇的。他为什么退圈？以前……很红吗？”

“那可不，他那演技……”

谢辰扬终于做出了他满意的香蕉饼，端着盘子来到客厅：

【爸爸出来呀~快来尝尝看我给你做的香蕉饼好不好吃。】

幽篁：“给我做的？是让我试毒吧。”

【我特地给你做的，离中午还有一段时间，现在做饭还太早了。】

他话音一落，桌上的香蕉饼连着盘子一起消失了。

【你怎么不按套路出牌呢？讲道理，你不是应该出来吃吗？】

幽篁：“监察组的人看着呢。”

【那你收进去吃他们就不知道了？哈？】

幽篁：“比起我化形出去吃，这个问题不大。”

呵，小崽子，还不就是想看我的脸。

唐哲彦和余嶂一起做饭去了。

严清站在办公室的落地窗前，眉目比起往常更显冷淡。

手机响了一声，他低头掏出来。

【我是小松的舅舅，下雨了，我记得你没带伞，要我去接你吗？】

外面不知何时下起了大雨。

严清面无表情地把手机塞回了兜里，没有回复他。

谢辰扬等了好一会儿没有收到信息, 又发了个信息。

【我做了午饭，有点多，你要来吃吗？】

余嶂和唐哲彦做好了饭, 严清却已经没了踪影。

余嶂在办公室找了一圈：“奇怪，这小子跑哪里去了。”

唐哲彦摆好碗筷：“打个电话吧。”

余嶂应了一声, 过了一会儿：“没人接, 算了算了，我们先吃。”

谢辰扬看着外面的大雨，惆怅道：【这个世界的媳妇，难搞哦。】

幽篁：“慢慢来, 等他高中毕业。”

【我可以辅导他的学习】

幽篁：“不要误人子弟。”

谢辰扬酝酿情绪，正想数落一番爸爸不爱他了, 就听到了门被打开的声音。

谢辰扬回过头。

严清浑身湿透了, 头发贴在脸颊上, 一只手撑在门边, 微微喘息。

跑得太急了。

谢辰扬惊道：“怎么不叫我去接……”

“叔叔, ”严清抹了把脸, “我进门可能会把地上打湿, 你介意么？”

“当然不……”

“那我去洗个澡。”

严清走了进去，反手把门关上，径直去了洗手间。

谢辰扬拿起拖把拖地。

【爸爸, 我怎么觉得他看起来怪怪的？】

幽篁：“谁知道呢。”

“叔叔。”

透着浴室的门, 严清的声音有些失真。

谢辰扬松开拖把快步走到了浴室外，调整好表情，声音温柔：“怎么了？”

幽篁指点道：“你后面可以加个嗯？低沉一点的那种，在温柔的同时，散发着成熟魅力。”

谢辰扬：“……”就, 有些懵。

“叔叔，我衣服都湿了，能借我一套衣服吗？”

“可以啊，我去给你拿。”

听着脚步声远去的声音，严清伸手挤了洗发露抹在头上，闭上眼，唇角轻微上扬。

呵，这个叔叔果然对他有企图。

正常情况下不是应该把陶小松的衣服给他吗？

他敢保证，一会儿他拿来的，绝对是他自己的衣服。

谢辰扬拿着衣服很快回到门外，轻咳一声：“小鬼，要我帮你洗吗？”

“你的手臂不是有伤吗？不方便吧？”

严清：“反正已经打湿了，我随便冲一下，很快，就不麻烦叔叔了。”

“喔，”有点小遗憾，“那我把衣服给你挂门外？”

“我好了。”

严清关了水，赤着脚走到门边，伸手打开。

谢辰扬瞳孔微缩。

严清伸手，面上带着淡淡的疑惑：“叔叔？”

谢辰扬眼神微微下移，看着他的小可爱，舔了舔唇：“给。”

严清伸手拿了转身回浴室，随手将衣服放在一边，拿起毛巾擦头发：“叔叔，帮我关下门。”

谢辰扬握住把手，缓缓地拉上，抬眸间一览无遗。

【爸爸，你说他是不是在诱惑我？】

幽篁：“什么？我看不见。”

【就是因为你看不见，所以，他果然是在诱惑我吧？】

谢辰扬低低一笑，捞起一边的拖把放好，

【他的神魂应该完全融合了，对我的爱也被唤醒了吧，所以才这样试探我。】

【但是，他还小，我得抵制诱惑。】

谢辰扬拿给严清的，是一件休闲裤和一件柔软的毛衣。

严清穿起来稍微大了一些。

他坐在沙发上，毛衣的领口就往下滑，露出圆润的肩头。
