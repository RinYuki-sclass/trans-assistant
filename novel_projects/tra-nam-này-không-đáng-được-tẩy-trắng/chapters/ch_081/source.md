# 渣男不配洗白 第81章

贺辰的父母在S城建立基地后没多久，就跟着H市官方的人一起来到了S城。

那时候的东城区还不是混乱区。

贺母没有异能，但好在贺父有异能。

他们最初的生活也还不错。贺父会跟着基地官方组织的人出去做任务，拿到积分换取物资。

他们一面打听着贺辰的消息，一面小心生活着。

后来又救了一个十八岁的男生，把他带在身边养着，还帮他一起找家人。

可惜，很快东城区老大就冒头了，逐渐掌控东城区。

不巧的是，贺父还在一次任务中断了腿。

他的异能等级也不高，行动不便，也不能再跟着基地官方组织的人去出任务。

他们的生活一下子就艰难起来。

好在基地并没有收回他们的异能者名额分发的房子，虽然房子小，但不至于没有落脚处。

这个时候，他们想搬到别的城区，已经没有能力了。

没有物资，没有能力，去别的城区也无法生活。在东城区好歹还有个房子。

当东城区被他们的老大管辖之后，东城区的人也无法再领到基地发放的普通人最低补助物资了。

任务倒是能接，但他们没有那个能力。

贺父断腿，行动不便。

贺母和他们收养的男生都没异能。如果是以前，他们还能领些不需要异能的后勤任务。

但，那种无需冒险的后勤任务，其他城区的人优先。

任务厅的人发放给东城区的任务，都是危险级别很大的。

贺母长得好看，很快就被人惦记上了。

她干脆而果断地毁了容，且打扮得越来越邋遢。

就在他们极度艰难的时候，他们收留的男生郭鱼表示他已经成年了，可以谋生。

然后，郭鱼却被东城区老大的一个手下看上了。

在他第一次外出任务的时候，就被强行掳去……之后，那个手下给了他不少物资。

郭鱼在外面哭了一天，才收拾好，带着物资回去了，说是任务所得。

次数一多，心细的贺母就发现了。

幽篁轻叹一声：“原身的母亲也是个性烈的，知道之后直接跟踪郭鱼，在那个混蛋对郭鱼做的时候，直接冲出去一刀砍了他。郭鱼都被惊傻了。”

谢辰扬不用问，就知道他们的下场不会好。

【现在的时间点？】

幽篁：“郭鱼那孩子已经被……了，六次了，再过两次，贺母就要发现了。”

谢辰扬算了算时间，那个时候贺辰已经听孙旭的准备带着队伍里的人离开基地另创一个基地了。

他到最后都不知道，在他要离开的时候，他的父母，在同一个城里，死亡。

谢辰扬和越清一进入东城区，就感觉到了暗中的一些视线。

东城区什么人都可以进，但能不能出去，就不一定了。

谢辰扬牵着越清的手，察觉到有人要上前，唇角微勾：“我是贺辰，星辰队的贺辰。”

作为基地里的唯三的五级异能者之一，贺辰的名字很多人还是听说过的，尤其是异能者。

暗中想要上前的人停下了脚步。

【贺辰的名头这么响，他父母没听过吗？】

幽篁：“前期贺辰还没闯出名头，等贺辰闯出名头的时候贺父已经断腿，他们生活陷入了拮据，没有继续出去打听，而东城区开始混乱，他们更是几乎不出门。”

【我就是觉得很不科学，这么大点基地，他们都在找对方，基地领导还帮贺辰找人了，竟然找不到】

幽篁：“……贺父在外没有报过自己的名字，倒是打听过贺辰的名字。”

【那基地领导找人的时候，就没找到过那些被贺父打听过的人？】

幽篁：“也许是剧情需要吧，贺父打听人的时候啥也不是，那些人听过就听过了，哪里记得住，天天都丧尸，寻亲打听人的也特别多……你懂的。”

【我还是有点想不通】

幽篁：“……”好烦。

就在这时，前面一个巷子里，一个面容柔美的男生提着一包东西一脸麻木地走出来。

幽篁：“那是郭鱼。”

谢辰扬抬眼就看出了，郭鱼的姿势不太对，面色也不太对，显然受了不小的痛苦。

第55章 这悲惨的末世温柔小受（五）

谢辰扬带着越清快步上前, 拦住了郭鱼。

郭鱼停下脚步，抓紧了手中的包，发白的面色紧绷着, 声音嘶哑：“让开。否则曾哥不会放过你们的。”

曾哥, 就是那个欺他的东城区老大的手下。

“曾不曾的无所谓，我主要是想跟你打听两个人, ”

谢辰扬笑道，

“我叫贺辰, 想找我的父母, 请问你见过或听说过贺文翔和周兰吗？”

郭鱼面色微变。

贺父贺母的名字他自然是知道的。

他撩了撩略长的刘海, 露出完整的眉眼, 认真地看着谢辰扬。

仔细看来, 确实能从他脸上看出贺父和贺母的模样。

郭鱼深吸了一口气：“我知道他们在哪儿，请跟我来。”

他身上除了这点刚得的物资，也没什么好被骗的了。

这两个人也不像是缺物资的人。

越清松开了谢辰扬的手, 神色淡漠的跟在郭鱼身后。

谢辰扬追上去，与他并肩而行。

越清没想到，谢辰扬这么快就能找到父母了。只是进了东城区, 只是随口问了一个路人, 就找到了。

他或许不在意他是丧尸, 但他父母呢？

他们很快就来到了一个房子外。

郭鱼把他们领进去, 开了其中一道房门。

“小鱼回来了。”

贺母放下手中的扫把，笑着抬头, 在看到谢辰扬时面色一变。

谢辰扬走进屋：“妈。”

贺母双眼一红, 别过头。

她本是个长相温柔如水的女人。

如今却头发枯燥凌乱，脸上一左一右两道伤疤醒目，皮肤也干燥起皮。

在这个时候见到了心心念念的儿子, 且他看起来过得很好。她为之欣喜的同时内心忍不住心生忐忑。

在末世前，他们的关系降到冰点。

如今再见，她和贺父一个毁容变丑一个断腿无力。他会嫌弃他们吗？

谢辰扬：“爸呢？”

贺母低着头抹了泪：“他在房里呢，他……”

她不知道要怎么开口。

基地内部网已通。

谢辰扬拿出手机拨打了一个电话。

“辰哥！”

“我找到我爸妈了，在东城区花屋巷9栋105，开辆车过来接人。”

“好的辰哥，我马上到！”

谢辰扬挂断了电话，往房里走去。

“小辰。”贺母叫住他。

谢辰扬疑惑地回头。

贺母舔了舔干涩的唇角：“你爸他……因为一场意外断了腿，现在只能在床上躺着。”

谢辰扬点头：“我知道了。”

说完，他就推开了房门。

贺父躺在床上，侧身背对着门。

幽篁：“他没睡着，而且在流泪。”

谢辰扬一怔。

幽篁怕他不懂，解释道：“他和贺母一直挂念着贺辰，但现在他们觉得自己成了拖累。他们既希望和你和好，又希望就维持末世前和你的冷战关系，不想成为你的负担。”
