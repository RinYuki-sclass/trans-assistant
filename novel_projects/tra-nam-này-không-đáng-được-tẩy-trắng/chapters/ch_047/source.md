# 渣男不配洗白 第47章

第31章 这悲惨的网游boss（三）

谢辰扬把剑插在地上, 席地坐下。

没有要和他交谈的意思。

向曲神情无奈。

老板一走，这人就变了啊。

“刚才你亲的那个，是我老板, ”

向曲坐在他不远处，拿卫修当切入口,

“你是看上他的脸了吗？”

“肤浅！”谢辰扬一只腿曲起, 胳膊搁在上面，“我爱的，是他的灵魂, 跟脸无关。”

向曲看着他, 就能看出区别来。

游戏里的伏鹰人设图他也看过, 是个对世界失去希望, 阴鹜暴躁的人。

而谢辰扬的眼神看起来就很温情。

不知道是不是因为谈到了喜欢的人的关系。

“你知道这里只是游戏吧？你看到的不是真正的卫总, 你不想和他来场真实的恋爱吗？”

听到他的话，谢辰扬：“我当然知道。”

向曲：“那你在这里等我，我会把这个副本封了, 你不要动，就一直在这, 好吗？我想办法让你出去。”

谢辰扬十分想答应，又觉得这样会落了魔尊的面子, 一时犹豫起来。

向曲再接再厉：“如果不出意外，卫总不会再上游戏了，你想见他，只能在现实里。”

谢辰扬闭上眼：“我知道了，你走吧。”

“如果一会儿你感觉到有什么在牵扯你，不要抗拒，是我们在帮你。”

“知道了。”

向曲下了线, 直奔公司。

谢辰扬倒了下去，看着澄澈的天空，有些头疼：“啊，我出去后真的要装作忘了游戏的事吗？”

“可以不用，”幽篁道，“你可以记得，只是被伏鹰这个boss的数据影响了，性格才会暂时变化，回到现实就好了，但记忆可以当作还有。”

“好麻烦啊，我就做自己不行吗？”

“也可以，但你和谢云耀本身的性格差距太大的话难免会惹人怀疑，你要是不介意的话当然没什么。”

谢辰扬不介意外人怎么怀疑。

但如果怀疑的人是他爱人，那就挺糟糕的啊。

“他就不能问也不问直接信我嘛。”

这话幽篁没法回。

他中肯道：“他不知道真实情况，也许会怀疑，但他的怀疑不是恶意，只是担心。”

谢辰扬突然笑起来，越笑越大声。

“？”幽篁无语道：“你笑什么？”

“这感觉就像是母亲吧？”谢辰扬勾唇，“操心儿子的感情什么的。”

谢辰扬没听到他的回话，闭上眼，在海风中逐渐沉睡。

卫修上线的时候，看到的就是他在树下安睡的画面。

卫修：“……”实锤了。

NPC是不需要睡觉的。

至少在智能化之前不需要。

“谢云耀。”

没有反应。

他撩起衣摆单膝跪下，伸手去拍他的脸：“谢云耀。”

该不会是技术部的尝试让他出问题了吧？

谢辰扬睁开眼，看到他的时候恍惚了一瞬，然后伸手把他捞进怀里，嗓音微哑：“我还以为你不来了。”

带着慵懒的睡意。

卫修一手撑在他的胸膛上：“别胡闹，我要跟你说正事。”

幽篁有些惊奇。

他宿主的爱人，和他所寄宿的原身越来越不贴合人设了，也或者，是只有在熟悉的爱人身边才会这样？

第一世的时候，翟致是真的很翟致。

以至于他没有第一时间发觉，这任宿主也是有人跟着的。

谢辰扬又闭上了眼，侧过身，下巴抵着他额头：“说吧，我听着呢。”

算了。

“我们公司的技术部尝试了，你的数据和伏鹰在这个ID里的数据结合得太紧密了，暂时没有办法安全的把你带出去，”卫修道，“你得等一等了。”

谢辰扬睁开眼。

【他们有尝试？】

幽篁：“有，在你睡觉的时候。以他们现有的技术，想要安全把你的数据剥离出去，有点难。”

【你帮帮他们。】

幽篁：“好。”

“谢云耀……”

“换个称呼。”

“……小耀？”

谢辰扬抱着他坐起身，邪笑道：“叫吾爱。”

卫修：“……”差点忘了，这厮还沉浸在boss的剧本里来着。

谢辰扬摸了摸他的头：“好吧，你想叫什么就叫什么。”

拥抱显得很亲密。

卫修却没有心生排斥，因此他有些疑惑：“我是不是在哪里……见过你？”

“嗯……”谢辰扬沉吟片刻，认真道，“也许我们上辈子，上上辈子，甚至上上上辈子都见过，所以啊，在这个世界上一看到你，我就一见倾心，不可自拔。”

说得跟真的似地。

谢辰扬拉着他的手覆在他的心口上：“我是认真的，难道你不觉得吗？对彼此，没有陌生感……”

他微微偏头，直视他的眼，理直气壮。

不知道是他心口发烫还是他手心发烫，他缩了缩手。

谢辰扬按住他的手，不满道：“跟你说话呢。”

卫修偏过头，淡淡道：“嗯。”

“我觉得我们就是几世情缘得以今生相遇……”

“够了，”卫修抽回手，“我来不是跟你说这的。”

谢辰扬：“不说啊，那就做呗。”

卫修：“？”

谢辰扬笑着凑过去，亲了亲他的唇角：“阿修，你感受得到的，我很认真。”

卫修闭上眼。

【GM小向：卫总，你跟谢云耀见面了？他在做什么？刚才数据波动很大，只不过时间太短了，我们还没研究出来，持续时间长一点，我们也许能够把他的数据和伏鹰的数据切开。】

卫修：【……知道了。】

谢辰扬坐久了，正想起身，就被卫修拉了回去。

“阿修？”

卫修吻上他的唇。

谢辰扬喜滋滋地回应。

嗨呀，爱人好热情。

卫修闭上眼，心跳起伏渐渐不平。

得承认，他说得对。

他们以前不认识，现实不认识，只是在游戏里见了第一面，他却一点陌生感都没有。

反而，欣喜。

也许前世情缘什么都不存在，但一见钟情是存在的。

卫修攀上他的脖子，努力拉长时长。

谢辰扬按着他的腰，恨不得就地办了他。

【我想……】

幽篁冷漠道：“不，你不想。他们在尝试切分你和伏鹰的数据，我在帮忙，也许下一刻，和你爱人亲吻的就变成伏鹰了。”

谢辰扬立刻软了。

他微微往后退了退，示意可以停了。

卫修紧搂着他的脖子跟着凑过去。

【在我数据离开的前一秒，把他踹开。】

幽篁：“啧。”
