# 渣男不配洗白 第163章

谢辰扬还是原来的表情, 就连那给人含情勾人的感觉的眼神也没有变化。

但云雪风就是知道，不是他。

此时在祁向阳壳子里的，是幽篁。

幽篁走到那人面前：“可否一叙？”

那人惊得手中的酒壶都掉了：“还真对我有意思啊……那什么, 小爷我……啊啊啊！松手！小爷恐高！”

云雪风看着幽篁将人提着飞进他们才出来的那个阁楼，眼眸深了深。

其他人都安静下来, 相熟的人用眼神交流。

在云雪风面前, 他们连传音入密都不敢。

无非都是围绕着：

这魔修胆子是不是太大了？刚才还和云雪风手拉手，现在就当着他的面去勾搭别人了？

云雪风是不是太纵容这魔修了？眼看着他们勾搭到一起了，竟没有动作？

云雪风望着阁楼的方向，眼神沉沉, 却没有丝毫动作。

阁楼上。

谢辰扬缩在体内，十分感兴趣。

认识那么久, 总觉父子情深, 但实则他对幽篁知之甚少, 除了个名字, 连他容貌都不知。

幽篁看着他抓着桌子微微趴着一副惊魂未定的模样：“能让我一探你是元神吗？”

恐高的后遗症过去, 他一手撑着脸仰头, 一声轻哼溢出,

“想骗我双修？我霍元逸可没那么蠢！”

幽篁：“只是一探。”

谢辰扬：“……”果，果然是父子吗！

他肯定也是想趁机神魂交流一番再说！

但这不是他们本来的世界。

难道……那霍元逸和他一样？

霍元逸伸手掏出一把折扇，晃开轻摇, 狭长的双眸中带着几分风流韵味：

“我说过你不是我喜欢的类型, 不过，你要是出去大喊一声云雪风是个蠢蛋，或许我可以考虑考虑。”

他轻叹一声，倾身上前抓住他的手：“你是要配合一些，不受苦楚, 还是想体会搜魂之苦？”

“别说笑了，你区区一个元婴，我可是分、分、分……”

霍元逸被他倏然爆发出来的气势给震得语气越来越弱，他抓紧扇子，

“你怎么可能……”

一个元婴期的魔修，怎么可能爆发出压制他的气势？！

霍元逸举扇：“我配合。”

幽篁：“……”还是这样。

谢辰扬弱弱道：“他要是死活不同意，你真要搜魂啊？”

幽篁：【怎么可能。】

就说嘛，他的爸爸那么温柔。

幽篁闭上眼，神识侵入霍元逸的元神。

谢辰扬不知道他们神识交流了些什么，安静地等了好久，幽篁才收回神识。

【怎么样？爸爸？】

幽篁轻应了一声，往外走去。

“等等，”霍元逸一手撑在桌上，双眼的慵懒和风流散去，直勾勾的盯着幽篁的背影，“你是谁？”

幽篁没有回答，纵身一跃，将身体的控制权还给了谢辰扬。

一时没反应过来，等他要稳住身体的时候，云雪风已经闪身过来抱住了他。

霍元逸也跳了下来，追问道：“你到底是谁！不……不是你，他呢？”

谢辰扬一惊。

他感觉幽篁演他挺像的啊。而且霍元逸和他才认识吧？就这么一瞬间，就分出他和幽篁两个人了？

莫非真如他所想，幽篁和霍元逸，早就认识？

幽篁：“监察组还在看着，虽然他们只是粗略看，但我不能明目张胆的现真身，你带他一起走。”

【他是谁？】

幽篁：“你的妈妈。”

霍元逸眯了眯眼：“说话。”

“妈……咳，霍元逸是吧？跟我们走一趟无我宗吧。”

“那当然。”

就算谢辰扬不邀请，霍元逸也会跟着。

他要弄清楚为什么他的元神对他没有任何排斥不说，在他有心抗拒时，元神却先他一步下意识的缠上了幽篁的神识，交缠时那种碰撞让他心悸，仿佛恨不得融入其中。

怪哉。

想他霍元逸风流潇洒数年，都是花草丛中过，片叶不沾身。

不应该留有情债啊。

此人诡异，定要弄清楚！

于是，无我宗回程的途中，多出了一个霍元逸。

宗主和其他弟子站在原地看着云雪风他们三人往他峰上飞去，久久凝视。

其中一个弟子忍不住道：“这魔修也太厉害了……”

“可不是，竟然有了太上长老还……还看上别人，还带回来来了！”

“魔修真可怕。”

宗主轻咳一声：“都散了，各回各峰，聚这儿干嘛呢？”

“是，宗主！”

云雪风在洞府外下了个禁制，带着谢辰扬进去。

霍元逸被拦在外面也没有生气，随手一挥，一个法宝落地，凭空生出了个小楼，进去一边温酒，一边开始回忆自己的人生过往。

“让我想想……有没有我不经意间结下的情债……”

洞府内。

云雪风将谢辰扬推坐在床上，贴上他的额头，神识很轻易地就入了他的领地。

他将谢辰扬仔仔细细的探查了一遍，收回神识：“你的体内和神魂都并无异常，那人是谁？”

谢辰扬伸手将他捞入怀中，微喘着亲吻他的唇瓣：“先不说这个，我们修炼吧。”

“是……何人？”

“是我爹！”

“你唔……”

“真是我爹，乖，先修炼。”

洞府外。

接到监察组已经离开的消息，幽篁在洞府外现身，一步步往那小楼走去。

类似这些法宝，都会有保护机制。

幽篁轻而易举的进去了。

霍元逸已经抱着酒壶靠在椅子上睡着了。

幽篁上前，伸手拿掉了他手中的酒壶。

霍元逸醒过来：“是你”

幽篁放下酒壶：“你的神魂为何残了？”

“生来便有，”霍元逸放松身子换了个姿势靠坐着，“那么，你究竟是谁呢？”

幽篁沉默地看着他。

“先是用别人的身体来见我，”

霍元逸声音低沉了几分，

“现在这个是真身吧？还带着面具……是长得太丑了，怕我看见？”

幽篁摘下面具。

霍元逸呼吸一顿，紧盯着他的脸，忽然反应过来，抓着衣襟急喘着，神色痛苦。

幽篁伸手覆上他的额头：“别想。”

“呼……”

“什么也别想。”

等霍元逸缓过来时，他已经倾身抱住了幽篁，头正抵在他的腰腹上。

他连忙后退，双手握着椅子扶手：“你究竟是谁？我的记忆从小到大没有缺口，像你这么美的人，我见后不可能会忘。”

但，他方才确实是因为脑海中出现了一段记忆才引起了神魂之痛。

当时应是看清了的，如今却已经想不起来了。

幽篁俯身抱着他，轻声道：“你愿意，让我查看你的记忆吗？”

霍元逸：“……”
