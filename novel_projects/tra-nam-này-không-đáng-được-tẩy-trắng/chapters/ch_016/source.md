# 渣男不配洗白 第16章

翟致回到公司的时候已经是中午了。

谢辰扬坐在办公室的椅子上，看到他的时候，眼中的暴躁和不耐一点没掩饰：

“和我一起到了公司后你人就不见了，翟致，我不是要插手你和朋友的约会，但你一个招呼没打，是不是有点不把我放在眼里？”

他在公司等了他一个上午。

最关键的是，翟致分明是和他一起来公司的，但他却是从邹浩的嘴里知道他的消息。

系统：“我可以查……”

谢辰扬：【不许查他！不许监视他！】

系统呵了一声：“放心，你不主动提及的，我也懒得费心思去做。”

第11章 这悲惨的娇贵公子（十一）

翟致慢慢走到谢辰扬面前。

资料里，他是个娇贵单纯的贵公子。

而相处中，他力气奇大，大大咧咧，偶尔会带着暴躁的情绪，虽然很多时候是压抑过后的。

他没有在他面前掩饰过。

往科学了猜，也许他有双重人格，也许以前的娇贵单纯都是他演绎出来的。

往不科学了猜……

谢辰扬看着站到面前，沉默不语的人，气道：“你说话呀！”

翟致低身抱住他，轻声道：“对不起，下次去哪里我都会告诉你，或者带上你。”

谢辰扬顿时泄了气：“……”

这么一说，怎么感觉他在无理取闹似的？

他解释道：“我没有生气，只是我们现在关系不一样了，你这样一声不吭……”

“对不起。”

谢辰扬轻轻推开他，站起身：“下次别这样了。”

翟致：“嗯。”

谢辰扬舔舔唇：“我饿了。”

翟致唇角微扬：“我带你去吃饭。”

楼下有一家餐厅。

谢辰扬因为嘴上还带着伤，吃的东西偏向于清淡。

系统安静地等他吃饱，才道：“看看网上，岑贺接受了采访。”

谢辰扬：【不急，等阿致吃完，回公司看。】

系统：“好的，我就是提醒一下。”

唯有任务目标，不需要谢辰扬吩咐，系统也会定时观察他的动态。

等他们回了办公室，谢辰扬才拿出手机上了网，点开了岑贺接受采访的那段视频。

面对记者们的咄咄逼人，岑贺露出隐忍的表情：

“我没有对不起阿阳，他现在身边也有别人。”

翟致声音冷凝：“他在暗示你先出轨，想要把目光转移到你身上。”

谢辰扬：“他在找死。”

很快，有个被叫徐家二少的人发了一个视频，打上关键词，@了岑贺和黎旭阳的微博，以及娱乐大V的微博。

配文道：

不巧，我住在黎旭阳他们家对面，那天下了很大的雨，我是准备拍个天气小视频抱怨一下这风雨夜的，没想到竟然拍到了这样一个视频。最近看到网上闹得沸沸扬扬，忍不住发出来了。

视频里，先是一个男声感叹道今天的风雨真大。然后就看到了对面的门，谢辰扬被推出来的那一幕。

男声“哇哦”了一声：“这不是黎小公子嘛，和老公吵架了？”

之后就是谢辰扬缩到隔壁墙角试图躲雨，然后被翟致命人送伞，带回家那一幕。

徐家二少在评论补充道：不是我说，那是黎家的别墅吧？至少我八年前住进来的时候对面就是黎家人了，那时候岑贺还不认识黎旭阳吧？岑贺能做出在这么大的风雨夜把黎旭阳赶出家门，反正我是不信他的“洗白”的。

系统：“视频是我发给徐二少的，配音是他后期配音我合进去的，没人能鉴定出来。”

谢辰扬：【遇到你我很幸运】

系统：“我每一任宿主都会给我好评。”

谢辰扬：【我也给】

系统满意地笑了。

黎旭阳的账号之前被认证为飞阳娱乐股东，现在也还是。

谢辰扬就在办公室和翟致自拍了一张照片发了微博：@岑贺你说的别人是指我少年时认识的邻居吗？脏东西，别胡扯，他不是别人。

【这是事发后小少爷第一次发声吧？】

【岑贺真是小人之心了，什么别人，分明就是发小，竹马竹马！】

【讲真的，岑贺吸着秦家的血，现在还把小少爷赶出去真的是太不要脸了】

【你们瞎吗？我觉得岑贺说的也有可能，你们看黎旭阳嘴上的伤，明显被人咬的】

【小少爷的邻居，肯定也是有钱人吧？有人认识吗？】

【说得对啊，岑贺就是个脏东西，最讨厌出轨的了，不行就离啊，吃着碗里的望着锅里的，什么东西】

【岑贺真的EX，好兄弟的女人都不放过】

【小少爷是被骗婚了吧？岑贺出轨个女的……他是不是根本就不喜欢男的？只是想骗小少爷的钱？】

由于那个风雨夜谢辰扬被赶出家门的视频，加上谢辰扬的回应，岑贺才刚开始运作的公关又崩了。

在谢辰扬的点头下，系统操纵着虚拟账号，以一当百，引导着舆论往岑贺骗婚、鸠占鹊巢、趁好友不在搞人家老婆等等上面引。

力求让岑贺黑到底。

是夜。

谢辰扬已经睡着，翟致坐在书房里，一手松散地夹着一支烟，一手握着鼠标翻看邹浩传来的资料。

资料与之前那份相差不大，只是邹浩还绞尽脑汁地多挖了些细节。

翟致靠在椅子上，戴着耳机，电脑上播放着一段视频。

那是黎旭阳在大学时被拍的一个视频。

视频是固定着的，一个阳光俊朗的男生笑眯眯地对着镜头：“感谢大家来参加我的生日聚会，旭阳，你可是说过，等我生日给我来一曲的，我要记录下来。”

黎旭阳穿着一件米色的小马甲，只是坐在那里，就显出他的贵气。

那双带着浅笑单纯的双眸，让人一看就是个不知人间疾苦的少爷：

“好，我给你作了一首曲，祝你生日快乐。”

黎旭阳的声音语速不快不慢，恰到好处，很给人好感。

翟致眼神冷淡地看着视频中的黎旭阳走到钢琴前坐下，弹奏了一首欢愉的曲子，唇角紧绷，时不时地抖一抖烟灰。

一点也不像看着自己喜欢的人。

视频没看完，他就摘下了耳机，把电脑关了。

不是他。

翟致回到房间，刚走到床边就被谢辰扬拉到了怀中，声音带着刚睡醒的沙哑：“去哪儿了？”

翟致推开他，掀开被子钻进去：“出去抽了支烟。”

谢辰扬低下头，扫了一圈他的口腔，淡淡的烟草味萦绕着，亲着亲着，睡意全无，他轻抚着他的唇瓣：

“我改变主意了。”

翟致：“嗯？”

谢辰扬微微挺了挺身子：“我想早点和你结婚，好洞房花烛。”

感觉到被顶着，翟致呼吸紧了紧：“那你得先和岑贺离婚。”

“好，”谢辰扬将手移到他的腰上环着，“睡吧。”

翟致闭上眼。

确认他睡着了，谢辰扬才睁开眼。

他轻手轻脚地走到衣架旁，一边换衣服一边道：【系统，睡了吗？】

系统：“……没睡。”

谢辰扬：【你知道岑贺的离婚协议放在哪儿的吧？】

系统：“能扫描到。”

谢辰扬：【跟我去隔壁一趟，我不想慢慢来了，速战速决。】

系统：“你要直接销毁离婚协议？”

【嗯】

系统：【你……不先去浴室解决下？】

【不用，一会儿就好了。】

系统：“……”行。

谢辰扬换好衣服，看了一眼床上的翟致，无声出门。

他□□进了隔壁，嗤笑道：【这房子目前还在我名下吧？我不算擅闯民宅吧？】

系统：“不算。”
