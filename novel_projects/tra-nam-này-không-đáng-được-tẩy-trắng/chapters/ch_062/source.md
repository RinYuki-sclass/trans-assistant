# 渣男不配洗白 第62章

柜子里装满了新衣裳，梳妆台摆上，各种首饰配饰琳琅满目。

谢辰扬看着换好的大红色床单锦被，戏谑道：“大人是想今晚就和我洞房吗？”

范温泽眼神移到了鸳鸯床单上：“这不是我吩咐的，他们大概误会了我的意思。”

安排的护卫：不是说给主君置办用品吗？主君都有了，还不洞房？

“哦？大人不想和我洞房？”

谢辰扬扯了扯衣襟，露出好看的锁骨。

范温泽视线上抬，看着他的脸：“我已往家里去信，言明我们的事情，待我处理好蓝州城事务，你可愿与我回曜国？”

谢辰扬把衣袍又往下拉了拉：“好啊。”

范温泽眼角抽了抽，冷着脸上前帮他把衣服拢上：“待我们回了曜国，再办婚事。没有小侍总是不妥，我已让人去买了两个小侍，你莫要拒绝。”

“……好吧。”

谢辰扬有些意兴阑珊。

【他变了，我都这样了，他还不动心】

幽篁中肯道：“因为你矮吧？”

【？？？】

【我虽然比他矮，但打起来他肯定打不过我】

幽篁：“……”还以为他变了，结果还是整天只想着打架。

范温泽让人买小侍的事是先斩后奏，见他同意了，这才道：“那我让他们来见你？”

谢辰扬：“不急。”

谢辰扬伸手一把将范温泽抱起。

没有防备之下范温泽下意识地伸手搂住了他的脖子，双腿环住他的腰。

谢辰扬咧嘴：“阿泽，我力气大吧？”

范温泽神色茫然。

幽篁：“……你幼不幼稚？”

谢辰扬微微抬了抬下巴：“阿泽，低头。”

幽篁：“……”卧槽，这声音，该死的苏。

范温泽心中一动，顺从心意低头，双唇相贴。

一吻结束，谢辰扬把范温泽放在床上，微喘道：“阿泽就不要和我分房睡了吧？”

什么隔壁房间，不如直接一间。

范温泽抓起袖子，抬手擦了擦他额上的汗：“不可。”

谢辰扬气道：“都这样了还不可？”

他猛地站起身，突然僵硬。

【我……我腰……】

幽篁：“早跟你说悠着点了，这身体本来就虚，你是有那个实力，但是你这身体没有，得好好养养。”

范温泽的手因为他的动作落下，淡定收回：“我们相识还不到一日。”

他不知道谢辰扬是急于脱离苦海，还是真的因为报答他的相助而以身相许。

这世道，男子孤身一人本就不好生存。

他已无家人，母亲是前任知府，且还嫁过人，身份尴尬。

但……他看着他的眼神，当真是深情极了。

一见倾心……也不会如此情深吧？

谢辰扬不知道自己急切的举动已经让他爱人产生了疑虑，他只想稳住自己的攻气。

他黑了脸，直接倒在床上，假装生气：“既然大人不愿意洞房，天快黑了，您请吧。”

范温泽眉头微蹙：“你生气了？”

“你快走，”谢辰扬沉声道，“再不走，我可不管你愿不愿意，直接拉你洞房。”

想起他方才抱着他亲了将近一刻钟也只是流了点汗，可见其力气。且他后背带伤，真要强来，他束手束脚，怕是要真的被他得手。

他站起身，轻声道：“我让人把那两个小侍带来。”

谢辰扬咬紧牙关没有吭声。

范温泽微蹙着眉头，犹豫了一会儿还是走了。

他一走，谢辰扬就憋不住地喘了几口气：【妈妈救我！】

幽篁：“不长记性。”

【爸爸救命！】

幽篁十分无语：“你就这么能屈能伸，爸爸妈妈张口就来？”

【我是个孤儿，遇到你了，你对我难道不像对儿子吗？你还是我和我爱人的媒人，从今天起，你就是我的父母了！】

“把母字去掉。”

【好的，父，先别说了，快救命，我好难受啊】

幽篁一手按着谢辰扬的后脑勺，一手给他揉着腰，陷入了沉思。

这……还真像老父亲在照顾不懂事的儿子？

等谢辰扬缓过来了，他回到了空间，戳了下组长。

幽篁：【组长，我宿主是孤儿吗？】

组长：【你管他是不是孤儿】

幽篁：【他说他是孤儿】

组长：【你怎么回事？老系统了，还不知道？他们的记忆都是假的，他说啥就是啥？】

幽篁：【那他是孤儿吗？】

组长过了好久才回道：【是，但他有师门】

幽篁礼貌道谢。

心想，带了那么多宿主，还没有哪个宿主想认他当爸爸的呢。

多一个儿子……吗？

范温泽离开后，让人把买来的小侍带过去，没有回房，而是站在院子里，眉头紧锁。

他从曜国带来的几个亲卫都姓言。

此时护在他不远处的，正是言颜和言语。

言颜一向胆大，看到范温泽陷入思索的模样，蹭过去：“大人可是有烦心事？”

范温泽：“你去查……”

“查什么？查主君吗？”言颜一下子就找到了点。

这念头是范温泽一闪而过的。

范温泽顿了顿：“罢了，不查了。”就……信他一次。

虽然疑点重重，但或许……谢辰扬当真是对他一见倾心，非他不可了呢？

他不也第一次见面就把人带回家，纵容他的胡闹，还……亲了么？

言颜：“……”

那两个小侍此时已经到了谢辰扬的门外，长得乖巧可爱，看起来只有十三四岁的样子。

谢辰扬看着他们，一时之间不知道要这两个孩子做什么。

“你们叫什么名字？”

“我叫沈书。”

“我叫赵小风。”

带他们来的护卫道：“主君若是不喜欢，可以给他们取名。”

谢辰扬摆手：“不用，就用原来的名字吧。”

护卫把两个小侍的身契交给他：“他们此后就是主君的贴身小侍，主君尽管教导。”

谢辰扬接过身契，轻啧一声。

教导。

这话说得。

护卫走后，沈书先询问：“天快黑了，主君可要沐浴？”

沈书：“那我去叫厨房烧水。”

“去吧。”

沈书走后，就剩赵小风一个人。

他有些无措：“主君，我，需要我做什么吗？”

谢辰扬摇头：“自己玩去，别离开院子，有事我会叫你的。”

这个院子是属于范温泽的住处，在里面的几乎都是他的亲卫，其他的也是把好了关的，这两小孩在这不会出什么事。

跑外面去，谁知道会不会遇到什么神神鬼鬼。

“好的，主君。”

眼看着赵小风转身，谢辰扬突然道：“等等。”

“主君？”

“去找大人，说我有要事找他。”
