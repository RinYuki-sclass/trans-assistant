# 渣男不配洗白 第4章

“好的。”

翟致走到床边，伸手拍了拍谢辰扬的脸颊。

谢辰扬睁开眼，眼神有些涣散，没有焦距。

“起来，吃药。”

谢辰扬稍稍回了神，伸出手，声音有些沙哑：“我有些软，起不来，兄弟帮帮我。”

翟致：“……”去你吗的兄弟。

他面无表情地伸手把他拉起。

谢辰扬身子一软，靠在了他怀里。

翟致冷声道：“故意的？”

“兄弟，别误会，我没有力气……”

谢辰扬语气真诚，那双微微泛红的眼睛温情脉脉地看着他。

翟致垂眸拿起退烧药凑到他嘴边。

谢辰扬低头含住，眼巴巴的看着他，含糊不清道：“水。”

翟致伸手拿起床头柜上倒好的水递给他。

就着水喝了药，谢辰扬把水杯还给翟致，神思越发清明了。

他软趴趴地倒回床上，狠声道：“我饶不了他！”

要不是那个渣男把他赶出来，他至于淋雨吗？他不淋那么久的雨，他会生病吗？他不生病，会梦到被火烤，会那么难受吗？

翟致低头看着他：“饶不了谁？”

“那个渣男，”谢辰扬红着眼，“等老子好了就干死他！”

“呵。”

翟致站起身：“那你赶紧好，雨早就停了，别赖在我家。”

谢辰扬这才想起自己还在寄人篱下，声音不由弱了几分：“再让我住一天呗，养养病，我现在没有力气找住的地方呐。”

翟致目光冷淡地看着他，没有说话。

谢辰扬小声道：“我可以交房租，我的银行卡在我的裤兜里……就我昨天穿的那套，丢在浴室了。”

翟致转身走了。

门被关上。

谢辰扬抹了抹眼角：“昨晚我就该直接冲出去把人砍了。”

系统：“宿主，这是个法治社会。”

谢辰扬装作没听到，闭上了眼睛。

第3章 这悲惨的娇贵公子（三）

谢辰扬又睡了一觉。

直到中午才昏昏沉沉地醒来。

“系统，我饿。”

系统：“……建议你出去吃饭。”

谢辰扬摇摇晃晃地站起来，打开门，一眼就看到了坐在客厅里和人在交谈的翟致。

他扶着楼梯扶手，有些犹豫。

和翟致说话的邹浩突然闭了嘴。

翟致回头看了一眼。

谢辰扬对上他冷淡的目光，腿一软，就滚了下去。

邹浩：“！”

系统：“！”

翟致家的楼梯铺满了柔软的地毯。

谢辰扬滚下去后跌在楼梯下的地毯上，有些懵。

系统委婉道：“我听说你的智商是没问题的……”

谢辰扬：“……”

系统安慰道：“我明白，你只是烧懵了，退了烧就好了。”

谢辰扬不想说话，也无力起身，自暴自弃地闭上了眼。

昏沉沉地睡了一晚上连带一个上午，什么东西都没吃，他头又晕，肚子又饿。

【系统，你现在给我一口吃的，我能跪在地上叫你爸爸。】

系统：“……”有些后悔绑了这么一个人。

说好的智商在线，战斗力爆棚呢？

分配部欺我！

翟致站起身：“去厨房把温着的粥端来。”

邹浩连忙站起：“好的。”钻进厨房。

翟致把他带来的资料塞到了抽屉里，起身走到楼梯下，脚尖碰了碰谢辰扬：“起来。”

谢辰扬颤巍巍的伸出了手：“兄dai……”

翟致冷冷地握住他的手，拉起。

见他就是起不来，翟致闭了闭眼，又睁开，蹲下身直接将他横抱起，抱到了沙发上，扶着他坐好。

谢辰扬软绵绵的靠坐在沙发上，感动的伸手握住了翟致的手：“兄弟，我不会忘记你的雪中送炭的。”

翟致垂下眸，没有抽开手。

邹浩直接端来一锅粥放在桌子上，看到他们交握的手，眼皮跳了跳：“我去拿碗。”

拿了碗勺过来，邹浩试探道：“要我……打吗？”

翟致抬眸：“你走吧。”

“好的，翟总。”

邹浩松了口气，大步离去。

谢辰扬早就在粥被端上来的时候就一直盯着了。

瘦肉青菜粥散发着的香味，让他空荡荡的肚子更是饥饿起来。

他松开翟致的手，想要坐起去舀粥，结果一个不稳，直接跪了下去。

他也不慌，就跪着打了一碗粥，一手撑在桌子上，一手拿着勺子红着眼边吹边吃。

系统：“……”不忍心看了。

翟致：“……”好惨一画面。

他欣赏了一会儿他的姿势，看他实在吃得辛苦，这才走过去按住了他的手。

谢辰扬抬眸，含情而勾人：“我还没吃饱。”

翟致握住他的手腕微微用力，见他放开了勺子，才扶着他让他坐好，面色冷淡地端起粥碗坐在他旁边，舀了一勺递过去。

谢辰扬：“烫，还没吹。”

谢辰扬见他没有要吹的意思，才委屈地自己吹了吹，一口含住勺子，把粥吃得干干净净。

见他吐出勺子，翟致机械般地又舀了一勺。

一碗粥很快见了底。

翟致又添了半碗。

谢辰扬看着锅里还剩下的粥，遗憾道：“晚上再吃吧。”

翟致见此，默不作声的把碗勺和锅都拎到了厨房去。

一阵凉风吹来。

已经吃饱，且大脑开始清醒的谢辰扬面色变了又变。

【系统，刚刚是不是原主那个小傻蛋灵魂归位了？这也太得寸进尺了！人家好心收留他，他怎么能要人家喂饭呢！还那么作！】

不就从楼梯上摔了下来吗？都是地毯，不痛不痒的，不知道自己爬起来吗？

还要人家抱！

不知好歹！

系统：“……宿主，你介意做一个智商检测吗？”

谢辰扬那双眼睛还是含着温情，勾人心魂的，但语气却森冷起来：【哦？你在怀疑我的智商？】

系统：“不是的呢。”只是宿主可能烧糊涂了呢。

谢辰扬往后一靠，闭上了眼。

身后传来脚步声。

他睫毛颤了颤，没有睁眼。

直到手机铃声响起。

系统：“宿主，是你的手机哦。”

他睁开眼。

一只纤长微白的手拿着手机从他身后递来。

谢辰扬拿起手机，也没看屏幕，直接划了一下就放到了耳边。
