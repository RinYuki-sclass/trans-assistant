# 渣男不配洗白 第19章

系统：“他是这个世界的人，会在这个世界轮回，而我们，会前往另外的世界。”

也就是说，不能再见的意思。

谢辰扬望着大海，目光有一瞬间的茫然：“我们在一起几十年，怎么我觉得就是一瞬间呢？”

系统心道，别说几十年了，几百年对你来说也是一闪而逝。

系统：“宿主，我们是现在去下一个世界，还是你先在这里休息一下呢？”

谢辰扬不语。

系统：“如果宿主不能调整好，我可以暂时帮你封印上个世界的记忆或者情感哦。”

谢辰扬：“不用，去下一个世界吧。”

系统：“好的。”

第13章 这悲惨的正派大侠（一）

谢辰扬在一张床上醒来，他的双手被麻绳绑在床头上。

他手一拽，用力扯开了麻绳，一手揉着发红的手腕：“这个世界怎么回事？”

系统：“看剧情。”

原身奚阳，名刀山庄庄主独子。

名刀山庄在武林正派中占着很重要的地位。

名刀山庄有一群杰出的铸造师，江湖上的其他门派的武器大多出自名刀山庄。

而名刀山庄的弟子又擅刀，有一刚一柔两套刀法，以柔克刚以刚克柔，合则刚柔并济，又有着特别难攻破的刀阵，在武林中可称第一山庄。

奚阳刀法卓绝，侠骨丹心，热血心肠。

如此人才，一遇渣男误终生。

渣男魏文彬，明面上是名刀山庄铸刀长老的弟子，实际上却是魔门派来的奸细。

他在山庄里伪装得阳光善良，在庄主的寿辰上奚阳喝多时，主动送他回房，趁醉睡了他。

醒来后一副被奚阳酒醉乱来的模样，慌乱无措。

奚阳是个负责之人，从那以后就对他上了心。

魏文彬也在步步为营之下，让奚阳对他越来越爱，越来越信任，以接触更多的山庄机密。

后来魏文彬把山庄都摸透之后，传信回了魔门，里应外合配合魔门击溃名刀山庄，禁锢铸刀师父，杀了那些不愿归顺魔门的人。

庄主性格刚烈正直，拼死到底，失了性命。

许多弟子也是宁死不愿与魔门同流合污。

奚阳自然也是打死不愿归顺的，决意死战到底。却被魏文彬给打晕，带回了魔门。

奚阳醒来后，自觉是他错信于人才导致山庄覆灭，无颜苟活，更不愿受制于魔门。

却被魏文彬以那些被抓来的铸刀师父以及一些年轻弟子威胁，只得苟延残喘，也不再给魏文彬一个好颜色。

魏文彬生于魔门，手段颇多，软硬兼施，一点一点驯服奚阳。

奚阳在折磨之下，虽不愿参与魔门任何事，不踏出院子一步，但也重新接受了魏文彬。

谢辰扬整理好衣服，穿上长靴，原本属于奚阳的清秀眉目染上一层暴戾。

“宿主？身上的杀气收敛一点。”

“收什么？山庄都被灭了，我现在就该一副大杀四方的模样。”

“……奚阳的内力被魏文彬废了。”

“没有内力，还有刀法，”谢辰扬摸了摸右手的刀茧，“奚阳的刀法印在我脑海里，我觉得就算没有内力，我也能以一当十。”

系统：“……”确定了，它家宿主的本命武器应该是刀。

就在它以为他要冲出去大杀四方的时候，谢辰扬坐回了床上：“系统，我想抽烟。”

系统：“之前你天天看着翟致抽烟，也没有要跟着抽的想法啊，怎么突然想抽了？”

谢辰扬脑海中回忆着翟致风轻云淡吞云吐雾的表情，又道：“我想抽烟。”

系统：“你上个世界有赊账，即使上个世界完成任务了，但最后也没有结余……”

谢辰扬低头。

系统：“……算了，给你兑一包烟，不算你利息。”

谢辰扬抬头一笑：“谢谢你呀，系统，哈哈哈。”

谢辰扬每天都能看到翟致抽烟，但他自己却不会抽。

在系统的指导下，他终于掌握了正确的抽烟姿势。

系统：“感觉怎么样？”

谢辰扬吐了一口烟：“感觉我每次吞吐间，嘴里都有阿致的味道。”

系统：“……”多经历几个世界，你就知道，跟你有一世情缘的，只是你漫长的生命中的一道过路风景。

谢辰扬连抽了两支烟，这才起身：“外面有几个人？”

“房门口守着两个人，院门外还有两个人。”

“现在什么时间？”

“黄昏已至，晚餐时间。”

谢辰扬扫视了一圈，试图找到能当武器的东西。

系统：“对了，你隔壁房间还有一个人。”

谢辰扬一顿：“哪一面？”

“东。”

谢辰扬贴到东面那堵木墙上，小声道：“隔壁的兄弟，在吗？你也是被魔门抓来的吗？”

隔壁没有回应。

谢辰扬嘀咕道：“难不成晕过去了？”

他话音刚落，就连忙侧身。

一柄剑插了过来，剑一转，木墙便裂开了一些。

谢辰扬转身拿起一个花瓶就往房门口砸过去，破口大骂：“魔门宵小！混账东西！有本事就放开我堂堂正正的打一场！”

外面守着的两个人相视一眼，讽笑一声，没有理他。

谢辰扬在房间里又抓了几个花瓶一边砸一边骂。

直到那堵木墙被那柄剑给开出了一条通道。

一个身着靛蓝色的青年持剑而来。

谢辰扬消停下来，心中一紧。

青年一双狭长的丹凤眼上剑眉飞扬，该是凌厉而张扬的。

但他那双眼中透出的神色淡淡的，在看到他时也没有一丝情绪起伏。

这是一张跟翟致完全不同的脸。

给人的感觉也并不像。

但谢辰扬却捂住了心口，直觉他就是他。

【系统系统！】

系统：“怎么？”

【他是翟致！】

系统：“你认错了吧，不像啊……”

【他就是！我的直觉告诉我他就是！】

青年在看到他的时候，冷淡的眼神微微动了动：“奚阳？”

声音清冽。

谢辰扬上前抓住他的手：“阿致……”

青年没有挣开，淡淡道：“你认错人了，在下隗津。”

谢辰扬感觉到他微僵的手，收回了手。

隗津把那只被他握过的手负在后面：“我听闻名刀山庄的消息，赶过去的时候已经晚了。”

系统：“隗津，在名刀山庄后面那个山头苦修的剑客，与名刀山庄交集不深，但也认识，他手上的剑就是出自名刀山庄。”

谢辰扬从不否决自己的直觉。

但面前的人已经不认识他了。

他按捺住把他扑倒的冲动，咧嘴笑着看他：“你是来救我的？”

隗津看到他明亮的笑容，手指抚上了剑柄：“不是。”

“但既然见了，我会救的。”隗津按住剑柄的手紧了紧。

他不是第一次见到奚阳。

但不知道为什么，这次见到他的感觉，与以往不太一样。

谢辰扬：“我们一起闯出去？”

谢辰扬的脸色其实不太好。

他被废了内力，伤还没好，脸上没有什么血色。

隗津垂眸：“等天黑。”

就快天黑了。
