# 渣男不配洗白 第158章

云雪风察觉到他元神并未受损，正想抽离，就被谢辰扬抓紧手，神魂缠上去，留住他。

云雪风担心强行离开会伤了他的元神，蹙着眉没动：“你……”

“好熟悉……”

“……”是熟悉。

云雪风内心也有疑惑。

他与面前这弟子以前并未相见，怎会觉得他的元神有熟悉之感呢？

趁他分神，谢辰扬放肆了。

云雪风反握住他的手：“住手！”

住手是不可能住手的。

祁向阳的记忆里没有双修之法，但谢辰扬无师自通了。

天色亮起。

云雪风一个掌风将谢辰扬击落玉床：“放肆！”

云雪风一心练剑，痴心大道。

除了修炼，便是与妖魔争斗。从未起过寻道侣之心，自然也就不了解双修之道。

一夜过后，他焉能不知？

谢辰扬一只手攀上玉床，靠在上面，舔了舔唇：“太上长老勿怪，弟子……情不自禁。”

云雪风面色冷极。

“别生气嘛，不过是神魂交流，”谢辰扬笑道，“弟子又没……真的冒犯您。”

他缓了一会儿内心的波动，转身离去。

“再有下次，逐出宗门。”

谢辰扬翻身坐在床上：【哈，看，就连生气，他都收敛了力道，不痛不痒的。】

【不过他的神识真的有些熟悉啊，难道是我们相恋多世，我熟悉了他的灵魂？】

幽篁没有回话，谢辰扬只当他去了空间还没回来，没再多问。

之后谢辰扬想去里面找云雪风，但被禁制拦住了。

云雪风这禁制，一设就是七日。

七日后他再出来，淡漠的双眸染上了一丝暗沉，彷如迷雾。

幽篁一眼看出：“他生了心魔。”

【什么？！】

幽篁：“他生了心魔。”

谢辰扬的脸色也不好了：【他都要飞升的人了，还能生心魔？】

“他道心动摇了。”

云雪风往外走去：“跟上。”

谢辰扬上前抓住他的胳膊：“你生了心魔？”

云雪风垂眸：“无妨，我会自行处理。”

“先去解决你的事。”

谢辰扬跟着他往主峰而去。

【爸爸，他真能处理？】

幽篁：“以他如今的境界，一个才产生的心魔，若想处理，并不难。”

幽篁：“……”但他的心魔多半是你啊，蠢儿。

主峰。

季宏和季然早已等在那里。

一起的，还有各峰峰主，以及他们的亲传弟子。

祁向阳的师兄师姐们也在。

【这么大阵仗，季宏有了对策？】

幽篁：“你猜？”

【哈，忘了爸爸你不能帮我了。】

“阳师弟，你竟真的修了魔？！”

“还真是啊，看这一身魔气……”

弟子们窃窃私语。

云雪风看向了季宏。

季宏见礼：“见过师叔祖。”

“见过太上长老（师叔祖）！”

云雪风：“开始吧。”

谢辰扬刚迈出脚步，季宏就道：“我六弟子祁向阳失踪多时，回来后沦为魔修，还指责是我儿害了他，如今，为了证明我儿清白，我要拿出法宝问魂鞭。”

谢辰扬挑眉。

季宏：“然儿，上来。”

谢辰扬笑眯眯道：“不是用在我身上吗？”

季宏斜了他一眼：“你已沦为魔修，谁知你有些什么邪门手段，既然你指责然儿，那便问问他，让他自证清白。”

“行吧。”

季然站到了众人中间。

季宏拿出问魂鞭，直入季然体内，缠住他的元神。

“季然，我问你，祁向阳说他修魔是因你所为，可是如此？”

季然神色晦暗地看了谢辰扬一眼，答道：“不是。”

谢辰扬轻笑一声：“师……哦，宗主，你这就刻意了。你直接问他，他有没有趁我渡劫攻击我，将我击入镇魔崖，不就好了？”

季宏顿了顿：“季然，你有没有趁祁向阳渡劫攻击他，将他击入镇魔崖。”

季然笑了：“没有。”

谢辰扬眼神微眯。
