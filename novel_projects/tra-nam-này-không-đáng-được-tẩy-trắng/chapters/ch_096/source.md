# 渣男不配洗白 第96章

装得跟没事人似的。

顾流吃着早餐，突然问：“我们以前是不是见过？”

“你想起来了？”谢辰扬一脸惊喜。

顾流：“……”还真见过？

他试探道：“你还记得，我们第一次见的场景吗？”

“当然……”

幽篁：“醒醒，他在诈你！而且，你一旦泄露你的真实身份和我的存在，那我们会被整出这个世界的。”

【他竟然诈我？】

幽篁：“在这个世界，你只能用蒋心辰的身份存活，不能让任何人确定你不是他。包括你爱人。”

顾流还在等着谢辰扬回答。

谢辰扬心中委屈：【他心机好深】

幽篁：“如果你没有记忆，一个初次见面的人说爱你要包养你，你恐怕直接一脚给人踹到死。”

他轻声道：“第一次见面的时候，是在大雨中，你送了我一把伞。”

顾流一怔。

送伞这种事他还真做得出来。

学生时代，他不知道送过多少伞给那些男男女女。

顾流心下好笑又无奈。

豪门温室里养大的少爷，就是这么容易感动吗？

当然，也不是个豪门少爷都是这样。

但面前这个，真的为了这点小事，就记着他，喜欢他。

怕是连这包养合同都是为了给自己找个台阶下吧？

实在是……天真又可爱。

谢辰扬见他不说话，扯了扯领带，起身：“走吧，我们去公司，挑剧本。”

顾流坐上了他的副驾。

顾流微微偏头，看着谢辰扬精致的侧脸，温情的眉眼，心中软了一下。

扶云娱乐。编剧部。

谢辰扬让人把筛选好的剧本都拿出来，给顾流挑。

顾流一本一本地看过去。

这些剧本都很有趣。

谢辰扬从中挑出一本递给他：“看看这个。”

“杀手良医？”

顾流从他手中接过剧本，看起了设定。

双男主。

一个曾经是让江湖闻风丧胆的杀手，后来成了救死扶伤的神医。

而另一个男主是身负血海深仇，被蒙骗后认贼为恩，是个初出茅庐的杀手。

“咦，神医枕无是双重人格？一个杀手人格，一个神医人格……”

故事很寻常，有点狗血。

但如果拍好了……

顾流：“这个立项了吗？”

谢辰扬：“你如果选中了，马上就可以立。”

顾流一顿：“其实，你不用对我这么……”

“别说那么多，”谢辰扬凑近他，“你就说，你想不想拍？”

顾流微微垂眸：“想的。”

“那就拍。”

《杀手良医》剧组很快成立。

这是公司编剧阿尧写的剧本。谢辰扬亲自联系了一个擅长拍摄武侠剧的导演，在公司筛选了一番，把合适的又没有档期的人安排上。

毕竟肥水不流外人田。

顾流演枕无，至于杀手归寂，来试镜的他一个都不满意。

幽篁：“不如你自己上？”

谢辰扬笑了：【这不太好吧？】

幽篁无语道：“你不就看出了这是隐晦的耽美，枕无和归寂是一对，才见一个杀一个的么？”

谢辰扬轻咳一声：【我怕我演不好，顾流会哭。】

【我不行的时候，爸爸能上吗？】

谢辰扬咧嘴，找上导演。

导演：“……”

谢辰扬又悄悄爬床了。

这段时间他每天爬窗，顾流一清二楚，但没有拆穿过他。

因为他最多是搂搂抱抱，或者亲上一口。

但今夜，当谢辰扬的手伸进他衣服里时，他隔着衣服抓住了他的手：“辰哥，适可而止。”

谢辰扬轻揉着他的腰：“我刚才看到一只虫子钻进你体内了，想帮你找出来。”

顾流好笑道：“那你找出来了吗？”

“没有，我再找找……”

“别闹了，撒手。”

谢辰扬放在他腰上的手微微一托，与他身体紧贴，呼吸交缠间，谢辰扬声音微哑：“我不想包养你了，不想做你的金主了，我要做你的老公。”

“好不好？”

就跟撒娇似的。

不知为何，跟他相处的时间越久，顾流对他就越容易心软，纵容。

所以他屡屡爬床，他也只装作不知。

“顾流，我想亲你。”

“顾流，好不好？”

“别说了。”

“好。”不说，他做。

当谢辰扬翻身吻住他时，顾流沉默了一会儿，察觉到他小心地试探，闭上眼，伸手环住他的脖子，开始回应。

谢辰扬眼中闪过狂喜。

【我这次真的憋太狠了！他终于回应我了，呜呜呜，爸爸，你自己去玩吧。】

顾流：“明天就开机了，别太狠。”

A市影视城。《杀手良医》剧组。

“时间快到了，两个主角还没到吗？”

“我在催，说是路上堵车了。”

“来了来了！化妆师准备……”

顾流冷着脸闭眼让化妆师上妆。

谢辰扬也坐在他旁边上妆，脖子上有个浅淡的齿印。

化妆师面不改色地用遮瑕膏将他脖子上的印记彻底遮住。

“顾流……”

“我劝你闭嘴。”

第65章 这悲惨的富二代（六）

导演在看到谢辰扬做好造型后的模样, 沉吟片刻：“你注意眼神，枕无的神医人格是爱笑又温柔不错，但你这眼睛看起来跟勾引人似的……”

谢辰扬也知道他双眼天生含情。

如果没有刻意去收敛, 就跟在刻意勾人一样。

经过那么多世界, 他的演技虽然比不上爸爸, 但是……

【爸爸, 开机第一场戏不想NG, 求帮忙！】

各就各位。

第一幕要拍的，是两位主角的初见。

枕无从武林盟那里得到了归寂的路线, 等在他的必经之路上。

镜头里。一条山道上。

顾流演绎的归寂一身黑衣, 背着剑缓缓走近。

他没有束发，一头青丝随着风胡乱飘散，露出的五官深邃而危险，在谢辰扬看来，好似一匹孤狼。
