# 渣男不配洗白 第119章

谢辰扬立刻道：“好啊。”

谷时雨去拿了吹风机插好，绕到他后面，眼神疑惑地给他吹着头发。

难道这次是真的太难受了？强撑不起来了？

也是，毕竟只比他大两岁。

看来昨晚在老房子睡觉，真的把他冷到了。

谢辰扬的头发不长，吹风机的风力又大，很快就给他吹干了。

谷时雨把吹风机放回去，又拿了保温杯给他倒了满满一杯热水，放在沙发前的桌子上。

谢辰扬笑眯眯的把保温杯握在手中。

【他真贴心】

幽篁：“你前面还说他蠢。”

【我说的是原本的谷时雨】

谷时雨看他握着保温杯不松手发怔的样子，不禁反思，为什么以前他对他虽心怀感激，但却不够体贴呢？

现在连他递个保温杯都感动成这样。

他心软了一下，声音都温柔了些：“趁着假期我已经在我学校周围看过了，有个小区环境不错，价格也不高，就是交通不太方便，但买个自行车或者电动车，二十分钟就能到我们学校。”

谢辰扬回过神。

以谷时雨的成绩，其实可以考更好的大学。

但为了离他近，选择了本省的大学。

“你想去B市读书吗？”

谷时雨双眸微动：“为什么这么问？”

谢辰扬：“你就说想不想，真心话。”

“想。”

谷时雨的记忆里，从小时候起，他就刻苦学习，想着有一天带着妈妈去大城市生活，想着以后出人头地，不让妈妈再那么辛苦。

可这一切妈妈都看不到了。

但他还是想。

如果可以更好，谁愿意耽于平凡呢？

不是说现在读的大学差，但师资肯定没有B市强。

谢辰扬勾唇：“那下学期转学到B市去，以你的成绩，肯定没问题。”

谷时雨：“可是……”

“不要担心，以前不提，以后我肯定会好好赚钱养你的！”

谢辰扬心中充满了豪情。

他要好好赚钱，好好养爱人，不用再这么精打细算磕磕巴巴地过日子。

谷时雨看到他眼中的亮光，和记忆里这两年来的灰暗和强打精神不同，现在的他自信而耀眼。

如果他能振作起来，忘了谷文奕那骗子，那努力一把去B市也不错。

课余时间，他也会兼职来补贴家用。

中午饭和晚饭都是谷时雨亲手做的，期间谢辰扬一直神色恹恹，不想动弹的模样，将装病进行到底。

幽篁：“苦肉计？”

【我不想睡客厅】

幽篁：“……”才第一天，就想要一起睡吗？

天黑的时候，谷时雨问：“真的不用去医院吗？都一天了，你还没好。”

“不用，等他自然好。”

谷时雨看了眼被叠在沙发角落的被子：“那今晚你去卧室睡吧，我睡沙发。”

“不行，”谢辰扬摇了摇头，眼中尽是温情，“晚上客厅很冷，没有空调，你还是睡卧室。”

这个家里，就卧室有空调。

“你生病了。”

“现在是我一个人生病，你要是睡了客厅，说不定明天起来就是两个人生病了。”

谷时雨无语了好一会儿。

谢辰扬轻声道：“要不，我们都睡卧室？”

谷时雨抬眸看他。

谢辰扬微微侧头，一副不好意思的模样：“冬天嘛，两个人……暖和些。”

幽篁：“……”没眼看。

谷时雨：“……”

谢辰扬：“我睡觉没有不良习惯，睡前是什么样子，睡醒后就是什么样子，真的。”

看他似乎有些着急，谷时雨眼中带着一丝清浅的笑意：“好。”

他刚才只是有点惊讶。

毕竟在入住这里的第一个冬天，他就提过一起睡卧室的事情，但是他拒绝了。

他以为他是因为喜欢男的，所以避嫌，也没看到他生病，就再没提过这件事。

两人都洗过澡，换了毛绒绒的动物睡衣躺在了一张床上。

一个兔子，一个狼。

当时有家店里的动物睡衣打折，保暖效果听说不错，宋扬就买了。

谷时雨虽然嫌弃，但也知道家里的经济，拿走狼的那套。

昏暗的房间里，谢辰扬不着痕迹的把手伸到了背后的兔子尾巴上，小小的一坨。

【讲道理，平躺的时候尾巴一坨抵着，不会不舒服吗？】

幽篁：“你可以把尾巴剪了，留一个洞。”

谢辰扬双眼一亮。

爸爸真是给他提供了一个好思路。

他可以把谷时雨的狼尾巴剪了啊！

就在谷时雨昏昏欲睡的时候，身后突然伸出一只手将他拥入怀中。

他心头一跳。

“宋扬？”

虽然宋扬自诩长辈，但他从来都是叫他的名字。

谢辰扬没有答复他。

后颈被温热的呼吸喷洒着，谷时雨略感不适，握住他的手想要拿开。

谢辰扬却反握住他的手，更贴近了他，还蹭了蹭。

谷时雨：“……”这人怎么回事？

说好的睡着是什么样，醒来还是什么样呢？

他抽开他手：“宋扬，醒醒。”

谢辰扬不仅没醒，还小声嘟囔了句：“冷。”

冷个鬼啊！空调开着，毛绒睡衣穿着。

偏偏他还挣不开。

有一瞬间，谷时雨怀疑他是不是在装睡，故意揩油？

但又觉得不可能。

如果宋扬真对他有什么想法，这两年他不至于一点察觉不到。

可能是生病睡得太熟了？

谷时雨折腾了很久，都没能把谢辰扬整开，自暴自弃的维持着这个姿势，朦朦胧胧的睡了过去。

次日清早，谷时雨醒来感觉到身后被抵着，心想，这睡衣尾巴怎么变硬了。

等意识到是什么时，他黑了脸，一把掀开了他。

谢辰扬顺势滚到了床下，茫然地坐起身：“怎么了？”

幽篁看着这一幕：“演技长进。”

【过奖过奖】

谷时雨看着他的表情，感觉他的反应似乎过大了些。

那也是正常反应不是？

就是姿势不对，才会这么尴尬。

谷时雨没有解释，起身去了洗手间。

谢辰扬眼尖地看到了他身下的不同，眼中溢满了笑意。

【我就知道，我不会拿不下他】
