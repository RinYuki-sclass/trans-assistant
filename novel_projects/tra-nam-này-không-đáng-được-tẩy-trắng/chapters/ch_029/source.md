# 渣男不配洗白 第29章

谢辰扬捏了捏他的手，

“就由我名刀山庄来为将士们提供武器，先拿下魔门，再整顿武林？”

隗津有些看不懂他了。

“名刀山庄也是武林门派。”

“我知道啊，”谢辰扬扬唇，“朝廷和武林早晚要对上的，我先表个态。”

隗津：“你要归顺朝廷？”

“阿津能代表朝廷吗？”

“我传信于我大哥，你与他谈。”

“你大哥？”

“他是一品将军。”

练武场。

烈阳堡堡主第一个站起来：“这个奚阳，真是不把我们放在眼里！与他爹比起来简直目中无人！”

“是啊，说是商议结盟，还没开始就结束了。”

“还不是因为烈阳堡连自己的弟子都管不住……被魔门奸细混进队伍都不知。”

“但奚阳确实过分了些，瞧他说的什么话？分明就是在赶我们走！不走还要收费……简直难看。”

紫炎府府主：“还不是你们见他年幼，一开始便没把他放在眼里。”

“他一个晚辈……”

烈阳堡堡主猛地起身：“我烈阳堡就先走一步了，我可不想巴巴的被人上来讨要伙食费和住宿费！”

说完，他拂袖而去。

刚出门就给了自己徒弟一脚：“那魔门奸细怎么混进来的！”

陆陆续续有人离开。

紫炎府府主看向还没走的名刀山庄守卫，轻声道：“可否请你们庄主来，我们再……”

常禄打断他的话：“不必，庄主说到做到，他既然说不结盟了，那便是不结盟了。”

“唉。”

紫炎府府主也起身走了。

心道，这奚阳到底还是年轻了些，意气用事。

最终练武场里只剩下了白鹤谷众人。

白鹤谷弟子：“少谷主，我们也走吧！”

他们为名刀山庄收拾，尽心尽力，结果那奚阳辜负了他们少谷主不说，走的时候显然也没把他们白鹤谷放在眼里，就这样丢下他们少谷主离去！

“再不走，人家可就要来跟我们收伙食费和住宿费了！”

也不想想看，他们白鹤谷为那几百人买的丧服、棺材和石碑等等，花了多少钱！

阮舟无奈道：“阿阳针对的不是我们。”

常禄上前，礼貌地行了个江湖礼：“庄主之言只针对其他门派，白鹤谷不在内，名刀山庄对白鹤谷的出手相助铭记于心断不敢忘，厨房已经在准备餐食，还请诸位务必留下。”

阮舟颔首。

常禄：“两位庄主稍后会亲自拜访少谷主。”

阮舟起身：“好，那我等便先回院子去了。”

等他们都走了，常禄才前往庄主的院子。

他到的时候正有个人领命退下。

常禄上前，将他与阮舟的对话说了。

谢辰扬给予赞赏：“虽然我走的时候有用眼神暗示他，但他不一定能看懂，你做得很好。”

常禄低头：“这是弟子该做的。”

现在他身为名刀山庄的弟子，白鹤谷对名刀山庄有大恩，那白鹤谷也是他的恩人。

自然不会放任白鹤谷的人误会。

常禄走后，隗津又去练剑了。

谢辰扬坐在躺椅上，一手拿着扇子轻摇：【好系统，还给赊账不？】

系统：“你要干嘛？”

【换点东西，给白鹤谷当谢礼】

系统：“给他们铸造一批武器不就好了。”

【不够。】

系统：“你想换什么？”

【一个比他们现在拥有的最好阵法还要好上一些的阵法，一个比他们现在拥有的药方还要好上一些的药方。】

白鹤谷以阵法与医术闻名天下，那他送的这两个东西，肯定是他们最想要的东西。

造一批武器就算是赠品吧。

系统：“……那需要差不多一百积分了，我不收你利息，你这个世界又要白干。”

【没事，我不喜欢欠别人恩情，一世积分还这恩，挺好】

系统：“行吧。”

所谓积分本来就是给宿主的历练生涯一些帮助，只要最后他的积分不是负的，它就不算违规。

就算是负的，他也能用自己的能量补上。

系统对于宿主，一直信奉着，能交好就不交恶。

也因此，它从未被前任宿主找过麻烦，甚至还收到过礼物。

系统：不愧是我，老系统了！

隗津练了一个时辰的剑，梳洗了一番后和谢辰扬一起往白鹤谷所住的院子走去。

“看了一个时辰，不倦吗？”

听到隗津淡淡的语气，谢辰扬一句他没有一直看差点脱口而出，到喉咙间才转了个弯：“只要是你，我怎么看都不倦。”

【给几分？】

系统：“十分。”

隗津：“哦？你不是中途睡了小半个时辰么？”

剩下的时间就是在发呆，真正专心看他练剑的时间，还不到两刻钟。

系统：“哦豁。”

谢辰扬心虚地憋出一句：“就算是睡着，我梦里也是你啊！”

系统：“真的？”

【虽然我不记得梦到了啥，但多半是他了】

他们到的时候，阮舟正端坐着和一个白鹤谷弟子下棋。

阮舟看到他，眉目柔和：“你们来啦。”

坐在他对面的弟子没有多余的动作，乖觉地直接离开院子。

谢辰扬：“……”我觉得他是不想见到我。

谢辰扬坐到阮舟旁边，拿出两张纸递给阮舟：“白鹤谷助我们名刀山庄良多，这是谢礼。”

阮舟伸手接过，看着看着，他面上的表情就变得严肃起来：“阿阳当真要把它们送给我？”

谢辰扬：“不然呢？”

隗津神色平淡地坐在他们之间，盯着棋盘。

阮舟小心翼翼的把他们叠好放入怀中，朝谢辰扬一拜：“我们所做不过举手之劳，也是家母所愿，阿阳给的这阵法与方子，千金不换，我无法抗拒这吸引，日后但凡名刀山庄有需要帮忙的，我白鹤谷必不会推辞。”

他拿出一张令牌，

“这是白鹤令，凭它可入白鹤谷，只要不违背白鹤谷的原则，什么都能做。”

谢辰扬：“哈，不用那么夸张，说是谢礼就是谢礼，除此之外，我们还会为你们铸造一批武器，你想好了想要什么武器，可以列张清单给凌弈。”

“这……”

“什么这个那个的，你去想想清单吧，这棋局我和阿津来帮你们破了。”

阮舟无奈，起身回房。

谢辰扬推了推隗津：“来来，下棋，让你见识下我的棋艺！”

隗津瞥了他一眼，转动了棋盘的位置，拿起棋子，落了一子。

系统：“你还会下棋？”

【不会啊，快快，告诉我怎么下】

系统：“……”不会你还这么理直气壮？

谢辰扬捏着一颗棋子，咧了咧嘴：“阿津啊，我们弄点彩头吧，输的人，今晚要无条件听从赢的人，如何？”

隗津：“好。”

谢辰扬乐了：【系统系统！好系统！系统爸爸！】

系统：“知道了知道了。”

在谢辰扬下了第二子的时候，隗津看着他的目光就微微变深了些。

随着时间慢慢过去，他的眼神越来越沉。

谢辰扬没有意识到，还在催促道：“快点快点，你要输了。”

又下了几子，隗津放下手：“是我输了。”
