# 渣男不配洗白 第151章

“帆……”

谢辰扬越过他，挡住了微微开启的房门，快步窜进去，毫不留情地关上了房门。

柯明晚了一步，拍着门叫他的名字。

严清在看到他要过来的时候就极为冷静地按掉了录像收好手机，只是还没来得及跑，就被钻进来的谢辰扬一把反压在了门上。

门外是柯明深情动人的忏悔声，门内……

严清心跳如雷。

谢辰扬担心他听到了“真相”会生气，强势地把人压住，只等着柯明离开后再解释清楚。

柯明没得到回应，两分钟后就没再发出声音。

他当然知道不会一次就能重新拿下人。

虽然场地和他料想的不一样，但谢辰扬肯听他说这么久的话，对他就不是无动于衷。

爱也好，恨也罢，他总能重新拿下。

柯明重新戴好了口罩和眼镜，迈步离开。

脚步声远去的声音在安静的环境里十分清晰。

严清：“叔叔，可以放开我了吗？”

“我看到了，”谢辰扬低头在他耳边轻声道，“你在偷拍。”

谢辰扬从兜里掏出手机，当着严清的面按掉录音：“我是在套他的话。”

严清：“……哦。”

“和他发生关系的，不是我本人。”

严清扯了扯嘴角：“他灌错人？上错人了？”

谢辰扬与他对视，眼中的深情和温柔几乎溢出：“我说，我没有和他发生关系。小鬼，你信吗？”

这视线太灼人，严清移开了目光：“不信。”嘴上说着不信，但莫名的，他心里就是信他了。

就是刚才听到“真相”时，他也下意识地想到了谢辰扬之前在他家说过的话，当时就信了他。

“我知道你信了，”谢辰扬低笑一声，揉了揉他的脑袋，“你的手机，收音效果好吗？毕竟这门和我们的位置还是有一段距离的。”

如果不信，这小崽子就不会乖乖贴着门没有动了。

“……还行。”

谢辰扬拉着他的手，打开门往外走：“那走吧，今天去我家。”

兜里的巧克力……好像现在送的话不合时宜。

陶小松玩游戏玩饿了，正在冰箱找吃的，一听到动静就连忙关上冰箱回头，然后满脸问号：“舅舅？清哥？你们怎么一起回来了？”

“我过来找你，刚好在楼下遇到了叔叔。”

严清面无表情的想到，现在你叫哥，也许以后就要叫舅父了。

陶小松：“害！我还以为你今天不来了呢，怎么来这么晚……”

严清跟着陶小松回了他的房间。

坐了一会儿，看到陶小松又沉迷游戏了，他才出门去了客厅。

谢辰扬朝他伸出手：“手机。”

严清沉默的把手机放到了他手上。

“密码？”

“……0403。”
