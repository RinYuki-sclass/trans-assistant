# 渣男不配洗白 第104章

“爸爸……”

谢辰扬刚上前一步, 头脑就一阵眩晕。

失去意识前, 他落入了一个沉稳有力的怀抱。

谢辰扬醒来时, 是在一个海滩的岩石上。

他躺在一张舒适柔软的床上，身上已经换了衣服。

他缓缓坐起身，发现身上的衣服虽然看起来灰扑扑的, 却很舒服。

【谢谢爸爸】

幽篁：“嗯，起来。”

谢辰扬下了床后，那张床就凭空消失。

他席地而坐，摸了摸已经包扎好的额头：【爸爸，我这次有点落魄啊】

“先看剧情。”

【嗯呐】

原身杨洲，父母在边城经营着一家小食铺，他们虽过得不富裕，却也不贫苦，日子过得寻常，一家人的心态都很好，生活得很安逸。

恩爱和善的父母，机灵俏皮的妹妹，杨洲过得很满足。

直到他十六岁那年，一个人出现在了他的生活中。

那是从怡州来的世家子，李承望。

他来边关东乐城，是因为他内心浩荡，想要出海探索大海之外的那些国度部落。

而东乐城临海，又有国内最强的水军，还有一些外商的船队。

他想来东乐城结识外商，与他们学习其他国家的语言，有机会的话，还想与他们一起出海，去他们的国家看看。

在东乐城暂居的李承望，每天都会到杨家食铺去用饭。

自然而然地，他就结识了原身杨洲。

杨洲一直生活在东乐城，虽见多了来自其他国家的人，但从来没与之交流过，一直安安分分地跟着家人经营小食铺。

李承望这样博学多才的世家公子，他是第一次见。

他偶尔见过的那些世家子，无不是鼻孔看人，即使不言不语，也让杨洲知道，那些世家子看不起他们。

但李承望不一样。

他博学多才，又生得风流，但却平易近人。

他来食铺来得多了，便经常和杨洲说起他的所见所闻，一点点地打开少年杨洲对外界的好奇心，探索心。

他仿佛什么都懂。

杨洲对他的崇拜日渐加深。

在李承望的有意撩拨和引导下，杨洲的心态渐渐发生了变化。

当这样一个他崇拜，可望而不可及的人突然跟他示好，表达了情意时，杨洲根本无法拒绝。

李承望仿佛什么都懂，包括亲密之事。

他带给杨洲的，永远都是美好温柔的。

杨洲觉得他是幸运的，遇到且得到了这样一个美好的人。

然后李承望要出海了。

他很聪明，在东乐城短短时日就学了许多国家的语言，并与一个他国的商队约好，带他一起出海。

这一去，不知归期。

杨洲舍不得他。

他也说他舍不得杨洲，并邀请杨洲与他一起去冒险，去见识更为广阔的天地。

杨洲心动了。

杨家人都很和善，也很开明。

他们听到儿子的想法，并不觉得惊世骇俗，反而还很支持。

拿着家里给的盘缠，杨洲和李承望承包的一艘船，跟在商队后面出了海。

入了茫茫大海后，他们的船掉队了。

李承望的贴身小厮说了一句遵公子命后就将他丢下了海。

他大难不死，被浪卷到浅滩上，却遇到了流寇。

他与流寇殊死搏斗，最终倒在了沙滩上。

那些流寇认定他要死，也没补刀，把他身上能捞走的都捞走后就散了。

杨洲身上伤口无数，肩膀上还被砍了一刀，他也以为自己要死了。

直到失去意识前，他都不明白自己做错了什么。

为什么他崇拜爱慕的李承望会突然丢弃他？

但他没有死，他又醒过来了。

还刚好遇到了一艘靠岸的船。

那船上的人都是其他国家的人。他被抬上了船，得到了医治。

不过直到回到东乐城，他也不知道救了他的人是谁，哪个国家的。

他听不懂他们说的话。

一到东乐城，他就被他们放下船，分道扬镳。

杨洲失魂落魄地回了家，才发现食铺已经是一片废墟。

邻居看到他，纷纷表示同情。

“就在你离开的那天夜里，你家就着火啦，那火大得，一下子就全烧起来了，我们救都救不过来。”

“后来只在里面找到了两具骸骨，大家估摸了一下，是你爹娘的。”

“水丫头也不知道哪儿去了，一直没出现。”

“大伙帮你爹娘收了骸骨，帮你给埋啦。”

被爱人丢入海中大难不死。

回到家中后却发现父母死亡，妹妹失踪。

杨洲差点崩溃了。

但他没有。他扛过了，他要找妹妹。

一个月后，东乐城又来了一队人马，找上了杨洲。

其中一个穿着富贵的人，年纪虽大，但面貌俨然就是杨洲年长后的模样。

那是怡州最大世家柏家的家主，柏庄。

杨洲出生的那年，正值战乱。

外出的柏家人在匆忙赶回怡州的时候遇到了同样逃亡的杨家人，并恰好在同一个破庙里生产了。

第二日，他们一方往边城，一方往怡州，就这样擦肩而过。

直到半个月前，柏母在和几个手帕交一起在茶楼相聚的时候，看到了一个才子画的《边城风光》。

那位才子的画作一向以细致入微为主。

也因此，伯母一眼就看到了边城码头上，双眼微微发亮望着海面的杨洲。

那幅画里的人足足有几十个，但她一眼就看到了他。

因为他无论是身形还是面貌，都与他丈夫年轻时如出一辙。

柏母内心巨震，一下就联想到了与他们夫妇长得一点都不相似的长子。

她强作镇定地回了家，与丈夫和盘托出。

丈夫立刻将那年跟他们一起的下人全部都召了过来，分开询问，威逼利诱，最终锁定了柏母的一个大丫环。

大丫环扛不住逼供，和盘托出。

原来，她曾悄悄爬过柏父的床。在柏父拒绝她，并警告她不要痴心妄想，安心伺候夫人后心生愤恨。

她并没想过柏父是念在她是柏母的陪嫁，没有发卖她，而是把她许给了府上的管事，甚至还允许她继续服侍柏母，是带着善意的。

那个管事虽然看在她是柏母大丫环的份上对她不错。但他年纪大，长得又不好看，她并不喜欢，内心更是怨恨了。

那晚柏母在破庙里生产，她看着她和穿着破旧的杨母都昏睡过去，一时冲动，就把两个刚出生的孩子给换了。

虽然她事后有些后悔，但她没敢坦白，毕竟……谁知道杨母他们是不是在逃亡的路上死了呢？若真是那样，连带着柏家的长子也死了，她的下场必死无疑。

之后她为了心里好过，对伯母伺候得很尽心尽力。

杨洲当然是不想跟着他们认祖归宗的。

在他看来，杨家父母才是他的父母。

但他们是世家，肯定很有分量……他提出一个要求，如果他们能够帮他找到妹妹，他就跟他们回去认祖归宗。

柏家人在怡州是世家之首。

边城的将军乐意给他家面子，他们一开口，就立刻派人寻找，最终，在一家花楼找到了杨芙水。

杨洲带着杨芙水和他们回了怡州。

杨洲认祖归宗，成为了柏家长子柏洲。

而原本属于杨家子的柏玉韬，成了柏家的养子杨玉韬。

杨玉韬享受荣华富贵十几年，一直以世家子自居，一下子变成了养子，他怎能甘心？

他厌憎柏洲，连带着也看不起被糟蹋过的妹妹杨芙水。

每每看到杨芙水，他总是出言不逊，言其残花败柳也配苟活于世。

杨芙水本就因父母身亡，受尽屈辱而郁郁寡欢，这来自“亲生哥哥”的多次耻辱目光，让她终于无法忍受，郁郁而终。
