# 渣男不配洗白 第117章

谷文奕对宋扬的亲近只有牵手拥抱，最多给他一个克制的亲吻，只是轻轻一碰的那种。

面对宋扬的疑惑，他珍惜道：“我相信你喜欢我，但你还不够成熟，未免以后你后悔，我想给你留有余地。”

我只是太珍惜你。

宋扬只觉得这男人真的太让人着迷了。

这么珍惜他，连带着都能克制自己！

只因为不想他以后后悔。

宋扬告诉他，他已经深思熟虑了，不是冲动。

为此，他回到家里和父母坦白，想要和谷文奕结婚。

宋父和宋母一直都很疼他，也很少干涉他的决定。

但这次，他们却坚决拒绝了。

他们一致表示，他们不干涉他恋爱自由，但结婚现在还太早了。

如果你大学毕业后还想跟他结婚，那我们不会阻止。

宋父宋母认真跟他剥析了现状，说他现在正要准备复读，而谷文奕已经在城里过得有声有色了。你难道不想等自己有点出息了，光明正大地跟他在一起吗？现在你还是个学生，和他在一起，你不惧留言，就不怕别人说他吗？

最了解儿子的还是父母。

他们这一说，宋扬就想清楚了。

于是他告诉谷文奕，这段时间他们就正常恋爱，等他大学毕业了再结婚！

学习还更刻苦了。

他可不想再复读一年。

谷文奕表面当然是赞许的。

宋扬不知道的是，谷文奕回来的这段时间，已经摸清了村子里各家的大概情况。

算来算去，宋家竟然是村子里最富裕的。

宋父宋母都是家中独子，在双方的双亲都去世后，他们继承了家里的大片田地。又只有一个儿子，平时用度不多，这些年来存下了不少钱。

和谷家的泥房不同，宋家是青砖瓦房。

事实上，谷文奕在城里做生意失败，还欠了不少钱。

村里人都以为他是回来安葬老婆的，其实他是回来看看这些年他老婆有没有剩下什么资产的。

从他出去后，他就没打算回来过。反正当初结婚他也没领证，就是在村里办了个酒席。

让他生气的是，家里除了个泥房，啥也没有，连田地都早就卖了给儿子上学。

本来他打算就这样丢下儿子走了，但撞上穿得不错，长得还不错的宋扬了。

他想了想，他还欠着债，就算离开也没有钱，说不定那些催债的还能顺着他的户籍找上门来。

宋扬看着又挺好骗的，年轻人嘛，一点感情就能骗得他找不着北。

本以为十拿九稳，竟然还要等到毕业？他哪有那个时间。

恰好让他在进县城买东西的时候在火车站遇到了打听他们村的一队人，看着凶神恶煞的就不好惹。

他觉得是催债的来了。

回村的路上正好遇到宋父和宋母，他脑补过催债的人会如何对他，怕得不行。

恶向胆边生。谷文奕看到周围没有其他人，就着宋扬学习的话题将他们带入了池塘边，趁他们没有防备，将他们推入了池塘中。

如果不是毫无防备，他们也不至于被谷文奕给推入池塘。

宋母是会游泳的。

她本可以把宋父带回岸上的。

但谷文奕在岸上拿着石头疯狂地往他们身上砸。

最终，他们沉下了水。

谷文奕心中很慌，面上淡定的又返回了县里。

他还特意到市场绕了一圈，看到了同村人，让其帮忙到谷家给儿子带个话，说是在城里遇到了朋友，要在城里待一天，晚上不回去了。

天黑了父母还没回家，宋扬当即就担心起来，找上邻居一起去找人。

在县里遇到过宋父宋母的村民道，他们中午的时候在县里碰过面，当时他们就已经准备回家了。

于是他们顺着村里到县里的路来回找。

直到第二天天亮，才找到了浮在池塘上的宋父宋母。

村里朴实，县里治安也很好，没人想过他们是被人杀害的。

有人说他们该不会是看夏天太炎热，想去池塘游个泳，结果不小心淹了吧？

宋扬说他的母亲很会水。

村民理性分析了一下，觉得可能是宋父不小心跌水里了，宋母去救人，或许因为抽筋或许因为宋父太重救不动，整得两个人都一起死了。

正值炎夏，浮尸不宜久放。

村民们热心的帮着宋扬办了丧事。

谷文奕回来之后十分懊恼，在宋扬面前多次后悔不应该为了朋友就留在县里没回村。

没人怀疑他。

宋扬更不会。

因为父母离世，宋扬突然成了孤儿，心中仿徨。

虽然父母没有跟人结过仇，但宋扬总不相信他们竟然会双双淹死。

但如果不是意外，又有谁会去害他们呢？

这个县里，都几十年没出过命案了，风气这么好……

谷文奕见他难过，经常想着各种方法逗他开心，安抚他。

宋扬陷在了他的柔情蜜意里，答应他和他一起离开村里，去大城市读书，和他一起生活。

宋扬已经成年，很多事都可以自己做主了。

他听从谷文奕的建议，卖掉了家里的田地和房子，连同父母留下的存款一起，加起来竟然也有二十多万。

这二十多万对以前的谷文奕不算什么，但对现在欠债累累的他来说无疑是回本的本钱！

他对宋扬更好了。

就在他们都收拾好行李要走的时候，谷文奕突然表示为难。

他说城里他因为以前都是一个人，住的地方是个一室的房子，三个男人显然是住不下的，他想先走一步，去置办新的房子，一切弄好后宋扬再带着儿子去找他。

宋扬体贴地同意了，甚至还想拿点钱给他。

谷文奕义正言辞的拒绝了。

谷文奕走后，宋扬和他的儿子谷时雨一起住在了泥房里。

宋扬是有手机的，每天都和谷文奕甜甜蜜蜜地发信息。

谷文奕到达H市后，拍了很多房型给他看，问他想要什么样的房子。

宋扬就去问谷时雨。

但是谷时雨和父亲关系冷漠，对于这个可能是后爸的人就更没什么好脸色了，完全不带理他的。

宋扬没办法，只想着日久见人心，他和谷时雨的关系会慢慢好起来的。

尽管他只比谷时雨大了两三岁，但也代入长辈的身份，面对他的冷脸毫不介意，十分包容，对他好得不行。

谷时雨表示，没必要。

就在谷文奕高高兴兴地打电话告诉宋扬，他已经买了房子准备装修，他们很快就能见面的第三天，宋扬一整天都没收到他的消息。

他以为他在忙，也没多想。

但当他晚上他就接到了一个自称来自医院的电话，说机主出了车祸，此时失去意识，医院已经进行急救，但要立刻缴费，否则会停止治疗。

宋扬慌了。

那人怕他不信，还拍了谷文奕躺在病床上，伤痕累累插满管子的照片。

宋扬信了，表示马上会买车票过去缴费。

那人问了他的地址，说他就算立刻买到票，转车转来转去，等到医院的时候也是一两天了，医院程序现在就需要缴费。

宋扬按照他的提示，连夜跑到了县城，找到了ATM机，把二十万都转进了所谓的“医院账户”里。

第二天天亮，他就带上谷时雨进了县城，准备要车站买票的时候，他才发现他不知道谷文奕所去的是哪个城市。

谷文奕走的时候，不让他去送他，说是看到他会舍不得走。

他连忙打电话给谷文奕，却发现他的手机关机了。

他有些茫然。

谷时雨察觉到不对，冷冷地说他肯定是被谷文奕骗了，让他去报警。

宋扬不信。

他觉得是手机没电了。

但是，之后的每一天，他的电话都打不通。

宋扬还是不相信，觉得他一定是出事了。

我们在这里等你爸爸吧，不然他回来找我们的时候找不到怎么办？

也许他的手机被偷了，也许……总之，他就是要等他回来。

谷时雨骂他蠢。

但宋扬不让他去报案。

他们就这样一起生活了两年多，谷时雨和他的关系也渐渐缓和，并成功考上了大学。

而宋扬自己，却没有再上学，而是在县里找了一份工作，供养谷时雨。
