# 第4章

蔺唯回来时，霍淇君和付小青两人正相对无言，性格如此也是无解，一个不会说软话，一个生性倔强，凑在一起就都没长嘴似的，不然也不会像原剧情里那样隔三差五产生矛盾误会，没个消停。

见他回来，付小青只觉得如释重负，霍淇君其实同样松了一口气，当然他是不可能承认的。

蔺唯坐定后先手指在桌上敲了敲，对霍淇君道：“你不是胃疼？先吃饭。”

“嗯。”霍淇君虽意外他还有心思关心这个，但也没表现出来，只绷着脸应了一声，拿起勺子有一口没一口地吃着。

付小青这才想起之前这人给她发短信说自己胃疼的事，之前还以为是对方没事找事，没想到竟然是真的。

“不严重吧？”她颇有些不好意思地问了一句。

霍淇君正想说没事，蔺唯就在桌子底下踢了他一下让他闭嘴，然后作为他的家庭医生就抢先一步开口了。

只听他煞有介事地叹息一声道：“还真挺严重的，长期饮食不规律导致的慢性胃炎，再让他这么任性折腾下去，我都怕哪天给他查出癌变来！”

语气既是玩笑，也有真实的担忧。

要不是每年都按时体检知道自己胃病不算严重，霍淇君都要被他这番话给唬住了，更别提付小青，癌变两个字一出，她顿时都不知道说什么好了。

要说多痛心吧也没有，霍淇君给她带来那么多的麻烦，之前就算真有过好感这会儿也不剩什么了，但她同样做不到完全无动于衷，毕竟是认识的人，这人还喜欢她，只是用了她消受不起的方法，听见他真有可能要不好，一时间还是觉得挺难以接受的。

蔺唯知道自己这么哄小女生多少有点缺德，但他这么做不是为了撮合男女主，而是付小青现在确实需要一份他能放在眼皮子底下庇护且薪资不错的工作，形势比人强，霍淇君的母亲实在是太强势了，她还是霍氏现在的实际掌权人，没人奈何得了她。

原作里他们两个分分合合那么多年最后能勉强he，前提都是这位坚定棒打鸳鸯不动摇的王母娘娘那时已经不在了。

霍淇君也已经意会到了蔺唯胡说八道的目的，因此没有拆台，默默吃饭。

然而蔺唯觉着他们三个坐在这，两个大男人围着一个姑娘家哄，总归不太得劲，因此犹豫片刻，他示意霍淇君先吃着，没管对方眼神里传递出来的不满，自己带着付小青来到酒吧角落一处座位。

“蔺唯哥，你想跟我说什么？”付小青有些好奇，有什么话是需要当着霍淇君的面用行动表示他不能听的？

那家伙脾气可不太好，刚刚过来的时候她余光看见他脸都黑得滴墨了，居然没当场发火，付小青都觉得挺不可思议的。

蔺唯顶着霍淇君好兄弟的身份，面对付小青，莫名有种替霍淇君心虚的意思，抬手摸了一下鼻子，他硬着头皮把自己想给霍淇君调理身体，刚好需要一个人帮他按需求定制一日三餐的事给说了。

付小青第一反应就是婉拒：“我知道蔺唯哥你想帮我，可是我一来不是专业的，二来我只想等风波赶紧过去，实在不愿意再跟霍淇君牵扯不清了。”

如果不是知道后面的剧情，蔺唯会觉得她的选择才是明智的，但是……

“你不了解霍老夫人，她是不会让这件事轻易过去的，除非阿淇立刻收心结婚，结婚对象还得她亲自来挑，否则在她那里，这件事永远过不去。”蔺唯有些不忍地看着她：“你或许能忍能等，你的弟弟呢？”

病人自然是耽误不得的。

付小青气红了眼眶：“她怎么能这样不讲道理！”

愤怒完又只剩下泄气，她比谁都明白现实不会为她的情绪所转移。

沉默良久，她才妥协般叹道：“就算我答应你，这样的法子，也不是长久之计啊。”

蔺唯都有些欣赏她了，虽然古早虐文总喜欢折腾女主，但也确实要性情坚韧的人格才经得起这份折腾而不会中途崩溃。

“这个你安心，船到桥头自然直，不过有件事还得你同意，我想先悄悄把你弟弟转移到我名下的一家疗养院去，我会安排专家团队给他治疗，这是保护他，也是我为阿淇招惹你为你带来的麻烦向你赔罪。”

蔺唯已经问过系统，在霍老夫人的眼皮下藏住一个病人，它还是能做到遮掩所有痕迹的。

付小青张了张嘴，到底没说出拒绝的话来，她没把握那位霍老夫人不会对她弟弟出手，也不舍得替弟弟推掉能得到专家会诊的机会。

“谢谢你，蔺唯哥。”付小青下定决心，深吸一口气道：“我可以答应你，但能不能我每天在家做好饭菜送过去？我不想……”

她有些害怕和霍淇君共处，而且明知霍淇君对她有好感，她既然已经没有那个意思，那长时间独处一个屋檐下也不合适。

蔺唯闻言倒是心下微动，他的任务主要是得看着霍淇君，如果能放在眼皮底下就再好不过了，虽然有系统在，有什么事他也能及时知道，但每次找借口出现也挺麻烦的。

八百个心眼子一打转，片刻后他对着付小青善解人意地笑了下，体贴道：“你家离得太远，你来回也不方便，如果不介意的话，用我家的厨房吧，反正我和阿淇现在住的房子是挨着的。”

付小青当然不会介意，答应得毫不犹豫，霍淇君要是知道自己居然被避之不及到这份上，估计又要破防。

等他们谈完，付小青先去找酒店经理辞去兼职，蔺唯则回到他们原来的座位，这会儿霍淇君早就已经吃完了，因为心里不痛快，故意把蔺唯那份也吃了个干净。

蔺唯回来看着桌上两个空盘子，唯一的反应却是：“不要暴饮暴食，下不为例。”

“……”霍淇君面无表情地扶了下眼镜，但好在后面的话听着顺耳多了。

“她答应了受我雇佣负责你的一日三餐，不过工作地点放在我家，到时候她送过去还是你过来吃，都随你。”

虽不是尽如人意，好歹答应了，霍淇君也能稍微减轻点对付小青的负罪感。

离开酒吧后，两人先送付小青回家，蔺唯开车，霍淇君理所当然地占了副驾驶，哪怕蔺唯跟他坦白自己不喜欢女人，他也不想这两人并排坐在他前面，可其实付小青压根没想过坐副驾，见他没有跟着自己坐到后排来，顿时长舒了一口。

一路上，蔺唯都在和付小青商量她弟弟的事，霍淇君插不上嘴更帮不上忙，他若是动用霍家的人脉，他家那位太后娘娘肯定瞒不住，到时候就纯属是帮倒忙了。

付小青对蔺唯本就印象不错，从前接触几次还只觉得是个脾气比霍淇君温和许多的贵公子，但今天蔺唯保护了她一次，她真正卸下防备跟他相处过后，才发现对方的温柔并不是出于教养浮于表面，而是真正平等的体贴周全。

她对于自己又要不得已和霍淇君扯上关系的惶恐，也慢慢被蔺唯的靠谱安抚住了。

唯有霍淇君全程一言未发，直到付小青下车，他也没跟人家说句再见之类的客气话，好在付小青早就习惯了他的臭脾气，压根没在意，再次谢过蔺唯之后就转身进了楼道。

等付小青一走，霍淇君才变了脸色。

“你真的不喜欢女人？”他看着蔺唯和付小青相处愉快，关系堪称突飞猛击，到底心里头还是有些不安。

蔺唯一边倒车一边回应他：“不然呢？我骗你这个做什么？”

这霍淇君倒是答不出来，毕竟原作里蔺唯在喜欢上付小青之后，就明明白白地示好了，至少剧情前期他是不怕霍淇君出手对付他的，毕竟谁能知道他的好哥们还顶着个主角光环，谁跟他作对谁倒霉呢！

霍淇君自己都不知道他有这‘特异功能’。

但有些事不问出来心里不舒坦，对着付小青的时候他半句人话都说不出口，对蔺唯他倒是没有这样的障碍，或许他潜意识觉得蔺唯为了安他的心都自曝隐藏多年的性向了，就当是投桃报李，他也可以相对坦诚一些。

“你不觉得你对她太好了吗？”就算蔺唯不喜欢女人，也不代表付小青不会喜欢蔺唯。

蔺唯看了他一眼，仿佛莫名其妙的人是他：“不然呢？你是希望我对她见死不救，还是任由你母亲抓住她弟弟当把柄？”

显然都不是，霍淇君有一瞬间的烦躁，扶了下眼镜道：“你对她的态度，可不像你说的不喜欢女人！”

蔺唯一本正经反驳：“我只是不喜欢女人，但我也不讨厌女人，好吗？我平等地绅士对待每一位女士，包括你的母亲。”

原身就属于标准的古早男二模板性格，蔺唯说这话半点不虚，他要是真为了避嫌突然对付小青冷淡拒人千里，才惹人怀疑。

霍淇君一想，好像还真是，这家伙一直都是万年不变温柔好脾气的样子。

但不能承认自己多疑理亏，他嘴角撇了撇道：“那怎么不见你对我也客气一点！”兄弟不如外人是吧？

蔺唯好笑地看了他一眼：“你是真不懂还是装不懂，我要是用温情脉脉的态度去对待一个男人，那只有一种可能。”

“什么可能？”霍淇君下意识追问。

蔺唯挑了下眉峰答：“我想泡他。”

“······”霍淇君顿时无言以对。
