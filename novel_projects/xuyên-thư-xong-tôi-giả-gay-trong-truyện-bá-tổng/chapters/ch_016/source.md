# 第16章

“怎么了这是？”蔺唯把入职的事处理好，回过头来就看见他俩谁都不理谁了，颇有些好笑地问：“这么短的时间都能吵一架？”

霍淇君不承认那是吵架，那明明是对方说不过他就恼羞成怒强词夺理，刚好付小青也这么想。

蔺唯没办法，只能把他们分开，付小青跟着经理去办入职手续，他陪着霍淇君在疗养院后面的公园逛一逛。

“这里环境还不错！”霍淇君没话找话，其实他还是有那么一点知道自己不占理的，只是他也没多愧疚，反正蔺唯现在喜欢的是他，其他桃花粘上来也是白费功夫，他伸手挡掉一两朵又不影响什么。

何况那个付天蓝看起来瘦弱又腼腆，和他完全是两模两样两个极端的类型，人的审美取向哪能这么两极分化？蔺唯肯定不喜欢他，要是有可能，早就私下联系上了！

“嗯，这里绿化做的确实不错。”蔺唯应了一声，迟疑片刻后，试着问：“你刚刚跟小青吵什么呢？”

不是他八卦，是这两人自从恢复成普通朋友关系后，不说多合得来，至少没再一言不合就互看对方不顺眼了，这突如其来的矛盾，他不能不关心。

毕竟他的任务是保证霍淇君在剧情结束的节点前不会胡作非为，但古早言情男主胡作非为的借口十次就有九次和女主有关。

尽管霍淇君这段时间表现得愈加正常，后来再没像酒吧那次试图随意处置别人。

“没吵架！”霍淇君下意识抬手扶了下眼镜，“只是在一些认知上，跟她产生了分歧！”

“比如？”蔺唯一看他这反应就知道他没理，不过这实在太正常了，他都懒得拆穿。

“比如你···”霍淇君心头微动，忽然问道：“你理想型是什么样的？”

“这我还真没想过，我不是跟你说了嘛，我觉得单身挺好的。”蔺唯嘴上接得自然，心里其实已经给霍淇君闹别扭的原因下了定论……八成是因为刚刚付天蓝对着他的表现，让这位疑似恐同的大少爷又应激了！

“而且你跟小青在我的理想型是什么样这件事上能有什么分歧？”蔺唯干脆堵了他的话头：“因为付天蓝？你觉得我但凡见到一个长得不错的男人，就可能对他有意思？”

“我不是这个意思！”霍淇君心一沉，停下脚步回头看着他道：“我没觉得你喜欢他，我只是不想你无意识惹一身桃花，而且…等等，你刚刚是在夸他长得好看？？！”

解释到一半忽然意识到什么，霍淇君原本的义正辞严立刻崩盘，满脸写着不可置信。

他问理想型，不就是想听蔺唯眼里的他是什么样子，结果不说就算了，还当着他的面夸付天蓝长得好？？？

“……”蔺唯这下是真不知道该说什么了，付天蓝本来就长得不丑，只是病了很久显得过于瘦弱了而已，女主的弟弟怎么可能长得难看，何况他又不是见色起意，只是平铺直述了一个事实而已！

两人对视半晌，蔺唯先认输，叹息一声道：“好了，我真的对人家没那个意思，如果你实在觉得别扭，我可以跟你保证，以后就算交了男朋友，也绝对不会把人带到你跟前来，行了吧？”

霍淇君闻言怔了怔，这才反应过来，原来他和蔺唯一直在鸡同鸭讲。

他自私的占有欲发作不愿意蔺唯太快转头去喜欢别人，本来还觉得这样的心思难以启齿，生怕被对方发现，结果蔺唯居然一直认为自己是在恐同？！

“我不是…！”霍淇君想解释，但又没办法向蔺唯剖白真实想法，最后也没能说出一句完整的解释来。

蔺唯并不在意他到底是不是，所以有没有解释都无所谓，只要霍淇君能保持现在的良好作风，等既定的时间一到，任务完成他就可以抽身离开了。

不过他又想到一件事：“既然小青已经离开，等回去，我也能从你家搬出来了。”

霍淇君更烦了：“哦！”

但蔺唯还觉得他挺乖。

系统总觉得他家主人滤镜有点厚：[他到底哪里乖了，我怎么一点没看出来？]霍淇君那张脸帅归帅，但面无表情的时候简直方圆十米内都生人勿近好吧！

[他看似脾气差，但实则也很好哄，总比以前遇到那些动不动就雷霆震怒，还劝都劝不住的霸道男主要好的多。]蔺唯不觉得自己审美有问题。

系统想了想：[也是哈！]

跟以前那些世界里，只要女主一出事就宛如狂躁症发作的男主一比，霍淇君这点一哄就好的脾气，跟猫猫哈气有什么区别？

这也是蔺唯对霍淇君一直表现得特别有耐心的原因之一。

两人在这边多留了一阵，等付小青走完全部流程彻底安顿好了才走，走之前本来还想上去跟付天蓝道个别，可霍淇君不乐意，付小青翻了个白眼差点没忍住当场戳破他那点上不得台面的小心眼。

当然最后她还是善良地忍住了。

回去的路上，霍淇君接了个电话，蔺唯本来没在意，只是系统突然冒出来提醒：[正在给霍淇君打电话的，是他办公室新上任的助理，霍老夫人的人。]

前阵子霍淇君为了跟霍老夫人对抗，把身边的人都换了一遍，因为原先那批人就是他刚进公司的时候霍老夫人交给他的，信不过，没想到新换上来的人里，还是有鬼。

系统继续道：[这人其实在原作里也出现过，他本来就得霍淇君信任，不然也不会被提上来，原作里就是他为了讨好霍老夫人，把女主行踪透给一群绑匪，导致女主被绑架还不小心流产了！]

这个剧情蔺唯倒是记得，只是原作里这个提供消息的人连名字都没有，只提了这么一嘴，他本来都快忘了，没想到这时候冒了出来。

等霍淇君通完话，蔺唯余光看了一眼，通话页面上显示着‘余助理’三个字，系统在脑海里嘀嘀咕咕，感慨这个余助理在原作里结局老惨了。

说实话，蔺唯觉得这结局是有点活该的成分在的，不过他任务所在，不能让霍淇君脏了手，那也只能设法提前把他抓出来了。

想到这，蔺唯装作不经意地问道：“公司的事准备得怎么样，什么时候需要我出面完成股权变更？”

霍淇君原本就打算在付小青离开后，开始搞事，既然蔺唯问起来，择日不如撞日：“就明天吧！我把方悦悦也叫过来，她手里也有一点股份，愿意转手给我。”

蔺唯反应了好一阵才想起这个名字：“就是上次和你相亲那个女生？”

“嗯是她，不过你别误会，我跟她纯粹是朋友！她这人熟悉了就有点神神叨叨的，不过还挺讲义气，你明天见过她就知道了。”霍淇君语焉不详，视线心虚地飘向车窗外。

“这又没什么。”蔺唯笑了笑，没放在心上。

车开到家时天都已经黑了，霍淇君眼睁睁看着蔺唯直接回了他自己那栋房子，啧了一声，有点不爽，这么干脆利落做什么？！

多住几天他又不会介意！

可惜他的心声蔺唯和他的系统都听不到。

隔天，蔺唯亲自做了早餐等霍淇君过来一起去霍氏，霍淇君吃上第一口的时候就震惊了，原来蔺唯厨艺这么好，衬得他过去几个月吃的付小青做的那些菜简直像是猪食！

电光火石间他忽然想起之前有一天晚上胃疼喝过一碗南瓜粥，后来他让付小青煮了几次，都没煮出那个味道来，他还以为是自己那天病着味觉异常，又或是记忆把那碗粥的味道给美化了呢！

所以，其实那碗粥是蔺唯做的？

他这么想着，嘴里也不自觉问了出来。

这‘人赃俱获’的，蔺唯也不好说那是外卖了，只得承认：“小青那会儿要备考，我就没麻烦她。”

“这样啊。”霍淇君心底微微发着烫，但也没多说什么。

之后两人到霍氏，霍淇君昨天晚上就通知了方悦悦过来，这姑娘不知为何积极的过分，比他们两个到得还早，这会儿已经在霍淇君办公室等着了。

霍淇君听见余助理这么说就头疼，但这一波肯定是躲不过去的，他只能深吸一口气回头看向蔺唯，道：“你还记得我那天在酒吧喝醉那次，跟你说了什么吗？”

蔺唯思考了两秒后点头，差点社死的记忆哪有这么容易忘。

“记得就好。”霍淇君没再多说，让余助理先去做自己的事，这里暂时不用他。

蔺唯则不明显地打量了这位余助理好几眼，若只看外表，确实是看起来就是个高效干练的社会精英，打扮也是西装革履一丝不苟的，完全看不出原作里不择手段的那一面。

他心里警惕地思考对策，结果一回头就见霍淇君黑着脸：“他好看？”

蔺唯没忍住笑出来，无奈道：“不知道的还以为你吃醋了，你拿我当贼防呢？”

“······”谁吃醋了！霍淇君心里猛打鼓，居然回怼的话都想不出来半句。

这时候听见外头对话的方悦悦忽然从办公室门口探出头来，视线在霍淇君和蔺唯身上来回几趟，眼睛都快闪出光来。

“霍淇君！这就是你说的那个，总是惹你生气的男朋友？”方悦悦情不自禁地感叹：“你男朋友怎么也这么帅？！”
