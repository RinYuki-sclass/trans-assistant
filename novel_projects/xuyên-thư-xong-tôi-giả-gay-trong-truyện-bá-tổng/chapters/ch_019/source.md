# 第19章

逛超市这种事，其实完全没有什么值得期待的，但霍淇君电话一挂就等着下班，心思不在工作上的时候工作，充分体会到了何为度日如年。

蔺唯来得不算晚，卡着下班时间发短信通知霍淇君下楼。

“怎么在下面等，不上去顺便跟我的助理打个招呼？”霍淇君一上车就忍不住阴阳了一句，说完酸得他自己都想撤回。

蔺唯看了他一眼，嘴角噙着一丝笑意继续开车，一边老神在在地道：“我要约他见面多的是机会，没必要这么削尖了脑袋似的见缝插针。”

“······”霍淇君怀疑蔺唯在讽刺他追付小青的那些日子，可那还不是因为付小青被他妈折腾得不愿意搭理他，他只能想方设法补偿！

还没等他想好措辞怼回去，突然反应过来，蔺唯这句话的意思，是默认他确实想追余瑜了？！

霍淇君心直往下坠，张了张嘴想说些什么，但又觉得他想说的那些没有一句话能真正说出口，顿时意兴阑珊。

蔺唯对他的反应早有预料，如果霍淇君上车的时候不那么猫里猫气地阴阳他，他也不会明知霍淇君现在听不得这种别有深意的话还故意说出来逗他。

不过逗过了就没意思了，不然一会儿吃饭还得看他垮着一张脸，该哄的时候还是得见好就收。

“我又不是那种见色忘友的人，现在当然是让你按时吃饭更重要，你有空想这些乱七八糟的，还不如想想晚上想吃什么。”

“你擅长做什么？”霍淇君脸色稍霁，给面子问了句。

“都还行，你挑你喜欢的。”蔺唯回想了一下原作里有没有提过霍淇君爱吃的东西，结果还真没想出来。

不过也是，要真重口腹之欲，也不至于经常沉迷工作忘记吃饭，最后把自己折腾出总裁男主标配的胃病了。

虽然蔺唯有时候总觉得，霍淇君的真实性格其实和他刻板印象里的霸总人设一直处于一种若即若离的状态，冷着脸一声不吭的时候固然是很能唬人，但蔺唯一想起这人能别扭到在办公室啃三天饼干都不回家，就很难不笑。

所以很多时候他愿意哄着，也不全都非得推给所谓任务，霍淇君本身的性格确实是有些不为人知的可爱在的。

一起逛超市的时候，这一点更明显。

霍淇君看起来更像只看什么新鲜东西都想手贱一下的猫了，经过生果区，蔺唯看着他连榴莲尖尖都忍不住伸手指戳两下，幼稚得跟他那身西装革履的画风格格不入，笑了下问他：“喜欢吃这个？”

霍淇君忙摇头，他受不了那个味道。

“那就别乱戳。”蔺唯把被他碰过的水果，除了榴莲外，其他不管有没有造成皮外伤的，都一股脑放进购物车里。

“你真是我活了这么多年，见过道德标准最高的人！”霍淇君撇撇嘴感叹，他收着力道的好吧！

蔺唯不以为意，拉着他离开了这相对脆弱经不起大少爷捣乱的区域，两人先后挑了些其他食材，本来这就可以回去了，但霍淇君觉得和蔺唯一起逛超市还挺有意思，就说还想再看看有没有什么想买的。

“那去看看零食？”蔺唯建议。

“好。”霍淇君可有可无地应了，事实上他不怎么爱吃零食。

琳琅满目的薯片辣条摆在货架上，蔺唯经过时还特意提醒，脆皮胃少吃这些，惹得本来没想拿的霍淇君没好气地笑了下：“那你带我来这边干什么？”

“也有你能吃的。”蔺唯抬了抬下巴，示意他看向另一边货架上的坚果。

“……行吧！”霍淇君勉为其难随手拿了两袋，实际上连包装上写的是什么内容都没有看清。

然后两人继续走，走着走着就到了和零食紧挨着的宠物粮区，蔺唯不由自主地停下脚步，拿起一个印着银渐层的罐头有些出神，这包装他还挺熟悉，在上一个世界里见过。

因为上面印的小猫和冰淇淋是一个品种，所以他一开始他总是下意识买这款，奈何……

“这个不好吃！”霍淇君看到他手里的罐头脱口而出。

说完不仅蔺唯怔住，他自己也愣了。

“这是给猫吃的。”蔺唯颇有些不可置信地问道：“你该不会…？”

虽然这东西基本都是人食级别，但霍淇君把它当普通肉罐头吃完还嫌口味不好这种事还是过于离谱了。

不过没咸味，他吃不惯倒是正常。

“我没有！”霍淇君听出他的言外之意立刻否认，但除了这两个字旁的解释也没有了，总不能说是他总是梦到自己变成蔺唯养的猫，梦里蔺唯给他吃过这个，他觉得不好吃吧？

真是见鬼了！梦里的东西，现实世界怎么还真有一模一样的！他从来没养过猫，脑子里对这些的认知应该是一片空白才对！

不过最让他受不了的还是令人想起来就脚趾蜷缩的梦境画面突然攻击了他，羞耻心炸裂的霍淇君转身就走。

“饿了！回家！”再在这猫粮堆里多待一秒他都觉得窒息。

蔺唯把手里的罐头放回原位，心里有片刻迷惑，旋即摇摇头不再多想。

回到家时霍淇君才总算从一个人的社死中调整过来心态，蔺唯让他先去换身衣服，等饭做好了再叫他过来，霍淇君没听，只把西装外套脱了，衬衫袖子折上去，理所当然地道：“我跟你一起。”

“…你别是来帮倒忙的吧？”蔺唯挑眉说了句笑，但也没拒绝他的好意。

“我就是不爱洗碗，总觉得脏。”霍淇君给自己上次的拉胯表现做了个解释，甚至还倒打一耙：“为什么你不弄个洗碗机？”

蔺唯耸耸肩道：“我平时又不做饭，要不是为了你，这厨房到现在还是个摆设！”

霍淇君下意识就想问那为什么蔺唯厨艺这么好，只是灵光一闪，反复品了品蔺唯刚刚说的那句话，就又默默不问了。

而在亲眼见过蔺唯做饭后，心里的猜测愈发确定，和付小青那种家常菜的随意不一样，蔺唯的厨艺很专业，这明显是特意学过的，至于为什么学了又不用……

蔺唯学了医也没给除他之外的人看过病，至于下厨，现在不就在做给他吃吗？付小青在这里住了这么久也没吃到过。

“你还给谁做过饭吗？”他不禁问。

蔺唯心想那可太多了，在当厨师的那个世界里，各大比赛的评委，和他在那个世界的徒弟女主都吃过。

但话不能这么说。

“没有了。”蔺唯随意答道，原身的男二人设里没有会下厨这项技能，他在这边煮了一次粥，做了一回早餐，这是第三回，都只有霍淇君吃到了。

霍淇君有一瞬间的满意，但很快他就又意识到，蔺唯如果只肯给喜欢的人做饭，那下一个吃到的多半是余瑜……

光是想想都觉得心里不得劲。

不过蔺唯这厨艺水平确实太超前了，很快锅里飘出来的香味，就挤走了霍淇君那些胡思乱想。

总体来说这顿饭霍淇君吃得还是愉快居多的，至少这一刻被蔺唯珍而重之特殊对待的人还是他。

霍淇君这种良好心情，一直持续了整个晚上，哪怕再一次梦见自己变成一只猫被蔺唯抱在腿上揉脑袋的恶寒情景，也没有造成太大的影响，直到上班没多久，他所在的整层楼，都因为一束玫瑰花而热闹起来。

玫瑰花是送给余助理的，送花的人并没有署名，余瑜收到后对好奇的同事也统一口径说不知道是谁送的。

他只对必要的人说实话，蔺唯虽然没有特意交代过他，但他知道这种事就是要故意低调些，才显得更自然。

霍淇君原本还没有想到花会是蔺唯送的，在他的印象里，蔺唯不像是这种喜欢用花里胡哨的手段追求对象的人。

所以其实一开始他是有些看热闹的意思在的，最好余瑜赶紧被追走，免得他心烦。

但这份幸灾乐祸的心并没能维持太久，他一时多嘴问了句花是谁送的，余瑜一点都没有犹豫地告诉他……

就是蔺唯送的。

霍淇君闻言还维持着面无表情，手却瞬间收紧，差点把笔给折断了。

“是吗？”他淡声道。

余瑜能年纪轻轻做到小霍总助理这个位置，哪怕过程中的手段不全是光彩的，察言观色的能力却一定非常人可比。

哪怕霍淇君习惯了对外喜怒不形于色，仍是让余瑜从他眉眼间的变化里捕捉到了一点不一样的情绪波动。

余瑜第一反应其实是怕的，蔺唯千算万算竟然没算到，霍淇君对他恐怕也有着超乎寻常的在意，只是看这情况，霍淇君只是本能地吃醋，对自己的心意并不明晰，否则对他恐怕不会还存着两分客气。

他当然会怕，只因霍淇君对于他而言，实在是太过得天独厚，若是不小心惹到对方，可能对方随口一句话，都会成为他生活永远无法承受之重。

但想到蔺唯给他的保证，这层害怕又渐渐褪去不少，重新浮上心头的，是一种诡异的优越感。

虽然是假的，可让霍淇君都不自觉流露出隐隐约约的嫉妒……

余瑜不着痕迹地深呼吸几下，才把那种令他头晕目眩的刺激感压下去。

霍淇君烦得很，实在不想看见他，摆摆手让他出去了。

半晌，他拿出手机发信息，都顾不上找借口了，开门见山就问：

『那花真是你送的？』

『嗯，怎么了？应该没有打扰到你的员工们工作吧？』

『我要是说有，你能下不为例吗？』

『可以啊，送他家去也行。』

『呵，那你还是送公司来吧，我还能蹭到点花香味！』

『……你喜欢花香味？』

『不喜欢！！！』

霍淇君快气死了。
