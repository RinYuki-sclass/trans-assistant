# 第114章 （完）

阮淇凌乱了好一阵后回过神来, 竟因为不愿意输阵这种理由，硬是板着一张通红的脸问：“怎么睡的，不细说说？”

在门口犹豫要不要进来的风陵铃实在听不下去，皱着小脸跑了。

她一走, 蔺唯和阮淇不约而同都往门口看了一眼, 又同时收回了视线, 默契地谁都没有提。

蔺唯轻笑一声道：“你真想知道？”说着他伸出一只手, 示意阮淇握上来：“这可不好细细描述, 不如我让你自己‘看看’？”

“………”阮淇沉默几秒，还能这样？该说不说, 他确实有点好奇，但真让他以第三视角去看‘他’和蔺唯做那种事的场景，还是…太考验廉耻心了。

“笨蛋，我开玩笑的！”蔺唯没等他内心天人交战完就忍着笑收回了手，但也没放过他，故意春秋笔法调侃道：“你这一转世, 脸皮倒是薄了很多, 上辈子好歹还会瞒着我去青楼对着春宫图埋头苦学……”

“闭嘴吧你！”阮淇羞耻得都快能徒手抠出一座魔宫了, 忍无可忍打断他：“谁知道你说的是真是假！”

他怎么可能做这么丢脸的事情！而且听着话音, 还被蔺唯当场抓包了！上辈子那个‘白痴’，真是丢尽了他的脸！

所以其实他还是信了的，不然也不会一听就恼羞成怒。

蔺唯见再逗可能要炸毛，忙把话题转移回炼器这件事上，提醒道：“虽然你这第一把是留给我的，不必太注重细节, 但塑型太丑导致我拿出来用的时候被人嘲笑，到时候你可别生气。”

阮淇一愣, 低头去看，这才发现手上这把玄铁扇已经被他无意识弄得看不出原来是什么样了，赶紧手忙脚乱往回补救。

有蔺唯帮忙，好歹还是救回来了，阮淇虽然嘴上说不求着蔺唯收下，但炼好后没管成品如何就直接装作不在意地丢到了蔺唯怀里，转而换了材料，选了个短笛的外形开始熟门熟路地炼制要给风陵铃的赔礼。

他确实是天赋异禀，寻常人学个几年才能入门的炼器之法，他磕磕绊绊地做了一次，第二次就像模像样了。

蔺唯把玩了一会儿勉强补救回来，但仍旧卖相欠佳的玄铁扇，对着桌面上的茶水轻轻一扇，茶杯外层迅速结了一层薄薄的冰晶，被子里的水则瞬间凝固成块冰块，因为成冰太过迅速，将瓷杯都涨出几道裂痕。

“还不错。”他评价道。

阮淇哼了一声，他亲手做的东西，自然不会差了，若不是刚刚蔺唯口出狂言分散他的注意力，还能更好一点！

蔺唯看着他夸一句都要尾巴翘上天的样子，又有些手痒，不过这次他忍住了，没再打扰阮淇专心炼器。

不过阮淇耐不住长时间的静默，且他对前世实在好奇，于是这回挑了个比较正常的问题开口问：“你我前世叫什么名字？”

蔺唯对他会问这个有些意外，不过想了想还真发现了之前一直没留意的盲点。

他的名字是不变的，这是每个小世界天道意识挑选安排后的结果，阮淇的名字也万变不离其宗才奇怪，所以这家伙必然也跟天道意识有些交集，并不是他下意识以为的依靠强大的能力擅自介入。

“我就叫蔺唯，你也知道我这一世是孤儿，又生而知之，因此名字是自己起的。”蔺唯随便找了个借口把自己名字敷衍过去。

转而说起阮淇的名字时，他本来是想说冰淇淋的，但还没开口就想起来，阮淇根本听不懂这三个字好玩在哪里，只会觉得这个名字听起来怪怪的。

最后他道：“至于你，你有很多个名字。”

阮淇不解：“我为何会有很多个名字？”他曾经化名阮淇，实际原名叫云淇，但这也就两个，他前世难道改名换姓许多次？

蔺唯轻叹一声：“这个问题就要问你这个作精了，总之你换了好几个身份接近我，因此才有了许多个名字，至于你真正本名叫什么，你并没有告诉过我。”

“………”阮淇平白无故又被扣上了作精的帽子，无语得翻了个白眼，他怎么可能不愿意告诉蔺唯他的本名，他顶多忘了。

并且其他地方听着也不靠谱，全是蔺唯的一面之词，介于蔺唯这个人表面看起来人品端方君子风度，实则对着他时总喜欢嘴上不饶人，也是很有些表里不一在身上的，他才不会随随便便听对方一说就什么都信了。

蔺唯也不在乎他信不信，阮淇现在又没有记忆，他就是真要算总账，也得等这家伙把所有事情想起来，只是不知道这要等这个世界结束，还是稍微刺激一下，阮淇也有机会自己想起来？

他想起霍淇君那一世，那是冰淇淋第一次化成人形追过来，所以没有太多顾虑与准备，因此当时的霍淇君其实是有一些零零碎碎的，关于自己上辈子是只猫的记忆的。

甚至还在梦里喵喵叫过，后来睡在一起后他又听到过许多次。

蔺唯也大概明白，当初如果不是因为霍淇君的这些表现让他认出来对方就是他的猫，从而多出了一层厚厚的滤镜，更加予取予求，那小祖宗也不会在那个世界结束后，误以为自己是因为冰淇淋而单纯爱屋及乌才答应跟他在一起。

不过蔺唯也没办法完全否认，因为那其中确实是有些移情作用，偏偏小祖宗的本体根本不是一只猫，他介意这一点才作妖，有了后几个世界失忆重开的这些事，蔺唯也不是完全不能理解。

所以他恢复记忆后，才在阮淇突发奇想变成猫给他摸的时候忍住了，一下都没碰。

又过了些时候，等给风陵铃的笛子炼好后，阮淇交给了蔺唯，让他去送给风陵铃，自己就不去了。

“她肯定不想看见我。”阮淇难得体贴，不过蔺唯还是从这句话里听出了几分得意。

蔺唯捏了捏眉心：“她现在多半也不怎么想看见我。”

不过最后还是他去寻了风陵铃，把阮淇做好的冰晶笛给了她。

风陵铃并没有闹脾气说不要他的东西之类轻视别人心血的话，她比阮淇要情绪稳定得多，经历了这次变故更甚，其实某种程度上说，她的外在性格和蔺唯更像一类人。

她接过通体晶莹的笛子，先是感叹了一句真漂亮，随后才抬起眼眸，轻声问：“大师兄，你与他…你很喜欢他，是吗？”

蔺唯从容点头：“你应当早就猜到了，我与他确实有着宿世缘分。”

“不，这与缘分没有关系。”风陵铃显然不是想要一个她早就猜到了的答案：“如果没有宿世缘分，你遇到他，就如同遇到这世上任何一个陌生人，你还会喜欢他吗？”

这个问题简直像是阮淇变成风陵铃夹带私货问出来的。

蔺唯想到这个可能低头失笑，而后认认真真地沉吟了片刻才道：“还是会的。”

套用系统一直吐槽他的话，阮淇那略显‘糟糕’的性格就像是长在了他‘怪异’的审美上，蔺唯或许不会第一时间察觉自己喜欢上了，但他情难自已的欣赏与纵容，还是会让对方先一步被套牢，然后反过来绑住他。

上一个世界里他和喻昭在一起的过程没有所谓情缘在其中干扰，也不存在任何移情作用，其实这一点早就已经验证过了。

所以还是会的，只是过程听起来有些讨打，为了不让隐藏气息偷偷跟在后面，现在正躲在草丛里偷听的那只猫听了生气，他就不那么详细分析给风陵铃听了。

不过虽然风陵铃没能听到他完整的心路历程，但还是从他说出来的这四个字里感受到了毋庸置疑的真心。

“那就好。”风陵铃释然地笑了笑：“你准备带他离开青云宗了吧？打算去哪里？以后多久回来一次？”

见微知著，确定了这两个人的关系，她就知道蔺唯在青云宗待不长了。

“去哪里要看他。”蔺唯想了想道：“我会每年回来一次的，不过我走后，青云宗的大部分内务，就要交到你手上了。”

一年时间在修真界根本不算什么，许多人闭关一次都不止这个数，因此风陵铃听后原本的不舍都消散了许多，只应下了接手宗门内事务的事。

谁让青云宗除了蔺唯之外，就她现在的修为最高。

蔺唯转身之际，风陵铃在他身后又带着笑意开了口。

“大师兄，虽然我很想纯粹地祝福你，不说什么煞风景的话，但思虑再三还是不得不嘱咐一句，如果他对你不好，记得回来，这里才是你的家。”

“……谢谢。”蔺唯面色古怪地应了，脑子里瞬间充斥着系统化鹅的笑声。

风陵铃这是把他嫁出去了？

算了，误会就误会吧，这种事也不好跟风陵铃一个女孩儿解释。

他若无其事地淡然走出去，余光瞥了一眼草丛里无意识晃来晃去暴露了都不自知的银色猫猫尾巴，犹豫片刻到底也没走过去把阮淇给拎出来。

回到小院时，阮淇已经提前他一步回来了，蔺唯缓缓走过去问：“事情都解决了，想好要去哪里了吗？”

“……啊？”匆匆忙忙赶回来装作一直都在小院待着的阮淇一个字都没听进去。

他在蔺唯面前素来不是很沉得住气，风陵铃最后跟蔺唯说的话，在他听来跟说坏话诋毁没什么两样，蔺唯愿意跟他走，他怎么可能会对蔺唯不好？！

有心辩解，却又不想承认偷听，以至于憋屈得不行。

“我问你，想好之后一起去哪儿了吗？”蔺唯好脾气地重复了一遍。

阮淇默了片刻后却闷声道：“听你的，我们要去哪里，当然得以你的意愿为主。”

“………”蔺唯心下颇有些一言难尽，这家伙平时可没这么善解人意，不是做不到，而是根本想不到去做。

[他这是被风陵铃一提醒，知道当人老公不能任性啦！鹅鹅鹅鹅鹅！]又到了系统最爱看的戏码之一了。

见蔺唯不说话，只一脸古怪地看着他，阮淇心头一梗，坚持道：“以前没有和人长久相处的经验，你放心，我以后会对你好的，绝对不让你难过。”

蔺唯捏了捏眉心，艰难措辞：“我没有那么脆弱，不会随便一点事就…难过。”

系统快要笑当机了都。

“还有，我只是要和你一起四处游历，你在想什么？”蔺唯觉得任由他这么发挥下去不行，于是话锋一转激他。

直钩钓鱼，奈何鱼很爱咬钩，阮淇脸色一变，这才想起来，虽然蔺唯恢复了前世的记忆，几乎是默认了他们俩的关系，但真论起来，他确实连一句喜欢都没给过。

阮淇被他钓得抓耳挠腮，最后心一横变回了小麒麟跳到蔺唯腿上，仗着麒麟真身脸红看不出来，脑袋埋进蔺唯怀里，闭着眼睛‘恶声恶气’地道：“你怎的如此吹毛求疵！我承认我确实喜欢你还不行吗？！”

表个白都听着像抱怨，天底下大概也只此一家了。

蔺唯笑了声，捏着他后颈把小麒麟提起来拎到面前：“你这么没诚意，我能说不行吗？”

“当然不可以！”阮淇听出他的调侃，倒也没有太急切，不过未免蔺唯真觉得他欠缺诚意，他还是变回来人形。

一时没注意这个姿势并不合适，结果就是他整个人都摔到了蔺唯身上，蔺唯眼疾手快将屁股下的凳子变成了躺椅，两人才避免了叠摔在地上的狼狈。

“这场景还有些熟悉。”蔺唯抱着他在躺椅上因为惯性而摇摇晃晃时笑道。

阮淇被迫跨坐在蔺唯身上，听了这话略有些不自在，他‘以前’不会还把蔺唯按在躺椅上做过吧？

猜对了一半吧！人确实是他按在躺椅上的，也确实是他主动要做的，只是过程和他想象的不太一样罢了。

“要不要我带你回忆一下，说不定你就想起什么了呢？”蔺唯忽然在他耳边道。

阮淇缩了缩脖子，但转瞬又来了精神，眼睛一亮看向蔺唯点点头。

于是一个透明的结界落下，笼罩住整个小院，若是从外面看去，就会发现蔺唯的院子就此消失在青云宗的视野范围。

院子里被迷昏头的阮淇懵然不知，还晕头转向地任由蔺唯摆弄，满心得意。

直到发现有些事与想象差距有点大，但箭在弦上显然已经来不及了，并且不争气的身体先一步投降，阮淇咬着牙不肯叫出声，试图保留最后一点面子。

但脑子很快像一团被搅拌过的浆糊，晕晕乎乎的许多画面重叠了这一瞬的欢愉，他差点丢脸地早早……

小院中微风习习树影摇动，有些事要结束，显然时间还早得很。

不知过了多久，等到院子里动静停歇下来，蔺唯轻喘着气撑起身，捏着阮淇的脸问：“刚刚是不是想起来了？”

后半段，这家伙下意识的肢体动作明显很懂如何获得最大程度的舒适，和前半段那个惊慌失措的小处男完全是两个样子。

阮淇本来还在努力平复呼吸，闻言整个人僵硬了一下，顾不上满身酸软立刻变回了麒麟想溜。

结果蔺唯悠闲地披上衣服，捏了个清洁咒把躺椅清干净坐下，然后静静看着他满院子慌不择路地乱跑就是跑不出去。

最后小麒麟没办法，只能变回了冰淇淋的样子窜回蔺唯怀里埋头装死。

“我又没说要怪你，你吓成这样做什么？”蔺唯在猫猫头上撸了一把才想起来：“这可是你自己变成猫跳上来的。”

“…哼！”猫埋头不出，但哼唧。

“你还好意思跟我哼哼？”蔺唯直接把他捞起来，剥夺装死萌混过关的权利。

猫猫顿时低头：“我错了！”

“我当然知道你错了，这还用你说？”蔺唯好笑道：“还是先告诉我你叫什么名字吧！”

“我就叫云淇。”这是真的真名。

蔺唯默念了一遍这个名字：“那我还是叫你阿淇吧。”

“嗯。”云淇应下，垂头丧气好一阵才憋不住问：“你…怎么还不开始生气？”

他都做好被暴揍一顿的准备了，可悬在头上的剑一直不落下来，故意折磨人似的！

蔺唯伸出手指点在猫猫额头，强行把云淇变回了人形，嗯，光溜的那种，然后抱着人去清洗。

“我没这么缺德，刚吃干抹净就对你发脾气！”

说着蔺唯又头看了眼忐忑不安的云淇，叹道：“而且我本来也没有很生气，只是你好歹跟我解释一下作妖的前因后果，再写一万字保证书，保证以后绝不再犯了，这点要求，不过分吧？”

“……哦。”云淇垮着脸应了，不敢在这上面讨价还价，他也知道自己很过分，不过重来一次，他还是不会改的。

蔺唯给他清理身体期间，他老实交代了自己作妖的原因，和蔺唯猜的理由大差不差，他就是觉得蔺唯最开始喜欢作为霍淇君的他时，动机太不纯粹。

“你就是喜欢他是你的猫！”他现在想起来都有点忿忿难平。

“他就是你。”蔺唯先纠正他，随后也不辩解，只道：“你猜我为什么不生气？”

言下之意是他最开始同意霍淇君试一试的要求时确实有被这一点影响，就是因此他才接受这家伙再三试探。

所以就不要指望他这时候会说出什么悦耳动听的谎话来否认了。

云淇气得想拿水泼他，但一想到这桶洗澡水的成分，还是算了。

毕竟现在是他理亏。

蔺唯又问：“那你到底是什么来头，能告诉我吗？不过如果说出来会让你有危险，可以不说，我并不是非要知道不可。”

“没什么危险。”云淇看了他一眼，小声道：“如你所见，我是一只麒麟，当初不小心受了伤才会落到你捡到我的小世界里，我生来代表着气运，对天道稳定尚未完成修复的小世界有帮助，所以祂们和我做了交易，祂们帮我追你，我答应祂们以后和你一起做任务。”

不得不说，云淇这算盘珠子都崩天道脸上去了，但这个诱惑太大，天道确实拒绝不了。

蔺唯听完后只耸了耸肩：“果然是天道意识帮着你坑我。”

云淇不敢吱声。

系统也恍然大悟：[难怪我居然完全没办法抵抗记忆被抽走，原来不是他，是天道意识帮他动的手！]

[我隐约记得你还跟他据理力争过？]蔺唯想起自己略有些迷糊的印象。
