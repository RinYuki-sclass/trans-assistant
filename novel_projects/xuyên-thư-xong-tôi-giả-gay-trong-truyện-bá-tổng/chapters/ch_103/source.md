# 第103章

眼下这群解救出来的几十个孩子, 仅仅是尚未被人贩子卖出去的一批。

其中男孩儿普遍年岁小一些，通常都是卖给生不出儿子的人家，年纪小不记事才养得熟，女孩儿则大多都有七八岁了, 十岁上下的都有好几个, 这样的卖给人当媳妇儿或是卖进青楼, 都不需要多费米粮养太久就能‘用上’。

男孩子还好, 送回家里后, 家中人没有不欢天喜地感恩戴德的，与之待遇截然不同的是女孩儿被送回去的时候。

被拐过的女孩儿回了家, 处境显然要复杂许多，家人看着找回来的孩子，垂泪的有，叹气的有，纯粹欣喜的，实在不多。

连百花羞送完几个女孩儿归家后都觉出不对来, 魔界是没有重男轻女这种事的, 这种事人类修士中也少有, 她还真没见过。

毕竟修行靠的是天赋和悟性而非体魄蛮力, 肉身体力上那点差距，在修真一途上完全可以忽略不计，这种情况下男性想压女性一头，如凡人一般用各种教条规训压迫女性的生存空间，在百花羞看来，那纯属是长得丑想得美！

这也是蔺唯不放心选择留下来看着的最大原因, 百花羞多半想不到这一点，蔺唯也不会对她如此责备求全, 阮淇过来之后，他便拉着人跟在百花羞后面善后。

蔺唯的法子也简单，他对那些找回女孩的人家说，孩子不是真的被拐走，只是来历不凡这辈子注定有此一劫，再当众展示一下仙术，给女孩儿赐福，凡人敬畏修仙者，不论家人还是邻里之间，自然都不敢再对那女孩儿苛责。

那些义正辞严的教条，遇到来自更高一层降维打击，也会‘识时务者为俊杰’的。

当然，蔺唯没有高估所有人的道德，包括眼下还是受害者的女孩儿们，他虽希望这些女孩儿能得到更好，至少是平等的境遇，但也不能肯定得了他赋予的特殊后，这些孩子长大了每个人都能满足于此，懂得抓住机会靠自己努力，而不是迷失于这种特殊做些损人利己的事。

因此他私下跟那些孩子约法三章，若有这样的行为，定会引来相应天罚，这是个实实在在的契约，而非他口头警告。

“你这样说不定将来还有人会因为明明可以不劳而获却不敢做而记恨你。”

阮淇在一旁看得分明，当中有个年岁大的，那活泛的眼神从劫后余生又加惊喜到最后难掩失望，他已经能预想到未来一定会出现这样的情况，不免替蔺唯不值。

“我想救她们，是因为她们确实处境堪忧，不该因为人贩子的错毁了一生，至于后面的警告，防患于未然，善始善终也是我的责任，否则不就是好心干坏事了？况且我只是把人性假设得很坏，不代表她们真的会变坏。”

蔺唯瞧着大多数女孩们根本不觉得他的做法有问题，这善与恶的比例已经不知道比世间平均值好上多少倍了，阮淇还不知足？

他见阮淇仍不开颜，只好换了种说法哄道：“说句不好听的，她们的感谢对我来说值什么？你怎么跟在给我当家似的，还一毛不拔，十份微不足道的感谢里少了一份都想替我讨债去？”

阮淇瞪大眼睛看向他，有这么狗咬吕洞宾的吗？他这都是为谁在抱不平！

“谁要给你当家？！”他眼睛一转哼道：“就你这样心大，哪天被卖了还帮别人数钱，到时候记得来找我就是，看在你帮了我这么多的份上……本尊养你！”

“行啊。”蔺唯不在意地笑了声，跟他开起了玩笑：“到时候只要我那位命定之人不介意，我就带着他投奔你了。”

“…我可不帮你养情人，只养你！”阮淇脸色顿时不受控制一垮。

蔺唯从善如流：“好，你养我，我自己养着他，行了吧？”

阮淇面无表情：“………”谢谢，也没有很行，还越听越气了。

蔺唯敏锐地察觉不能再逗了，这家伙听不得这俏皮话，再逗大概率要翻车了，这才转移话题：“说起来那日惩罚百花羞的法子，本是看在你的面子上，不想弄得太难堪，临时想的，没想到还能有这样的意外收获。”

“收获在哪儿？”阮淇还在生气，听不进去一点，拿他的原话怼他：“一堆微不足道的感谢夹杂一份恩将仇报的怨恨？”

“你乐观点！这不是还有一个被迫跟我化敌为友的百花羞嘛！”

蔺唯看得很开，虽然他也明白百花羞多半只是怕了他，但这样也好，将来哪怕只是碍于他的威慑，应该也不会再像前段时间找他麻烦一样，一言不合就对风陵铃动手。

他可以不惧，但他师妹那元婴大圆满的实力对上百花羞就够呛了，他和阮淇无论是谁都不能时时刻刻把风陵铃踹在兜里带着，更别提打起来还容易触发女主光环，风陵铃或许不会有大事，但是一定会殃及池鱼！

他是不指望能根治好恋爱脑了，百花羞若是光明正大追求阮淇他也没资格管，别再走原作剧情去对付风陵铃就好了。

阮淇想了想也是，他和百花羞认识这么多年怎么说也有两分香火情在，虽说肯定没法跟蔺唯…和人家师妹比，总归蔺唯能应付得来那女人就最好了，若非被逼狠了，他也不想对百花羞下太重的手。

等百花羞把孩子们都挨个送回家，她才顶着阮淇的虎视眈眈，扭扭捏捏地找蔺唯询问了她觉得不对劲的地方。

蔺唯耐心跟她解释了，也把自己跟在后面做的事一并说出来。

百花羞和阮淇一个反应：“肯定会有人反过来怨你呢！这事在魔族屡见不鲜了！”

“我知道，你们尊上跟在我身边看着都生了半天闷气，所以我才自己来。这事你已经做得很好了，我的话作数，这就替你解开骨鞭上的禁制。”

他想了想又道：“不过还有很多已经被卖掉的孩子需要分散人手去各地解救，那人贩子让你搜过魂后也没法再搜第二次了，所以还要麻烦你把剩下的名单写下来，我传讯回师门，让师弟师妹们接手过去。”

百花羞忙点头，这是小事。

等她拿着解封的骨鞭美滋滋地跟蔺唯这尊惹不起的煞神告辞走远了，才发现自己竟然把阮淇给忘到了脑后！！！

僵硬片刻后，百花羞肩膀一塌，算了，有蔺唯在，她也不敢搞什么幺蛾子，而且不知道是不是她的错觉，阮淇似乎不太喜欢她靠近蔺唯。

本来她是有点无语的，她哪里还敢对蔺唯放肆？她对蔺唯的态度比对阮淇还好，尊上简直是杞人忧天！

但现在有点回过味来了。

她后知后觉意识到，阮淇不喜欢她靠近蔺唯，不是觉得她有危险，而是觉得她有威胁！所以她态度越好，阮淇脸色越差！

百花羞抬手摸了摸自己绝色的脸蛋，说不出被喜欢的人当做潜在威胁者的滋味，但这可是来自魔尊对她美貌的绝对认可，她压住蠢蠢欲动想要往上勾的唇角，默默把心酸咽回了肚子里。

另一边蔺唯拿着百花羞留给她的名单又回了青云宗一趟，为了避免麻烦，他让阮淇自己乖乖隐身。

“你可以去师妹那儿看看，不过不许让人发现了，我交代好所有事情再来找你。”

阮淇默了一瞬才道：“没这个必要，她又没醒，我上回已经看过了。”

他认定了蔺唯喜欢他，对蔺唯这种劝他去看顾情敌的行为，心里有点替他难受，没多犹豫就拒绝了对方的委曲求全的提议。

实在是他本来对此也没有很强烈的欲望，但这一点他暂时还不想承认。

蔺唯颇为意外地看了他一眼，但也没说什么，他是风陵铃的师兄，也是她的娘家人，对原作里的原配行个方便可以，但强推着外人去看望自己师妹的事也做不出来。

而且只说风陵铃本身也不需要，她这时候还没有喜欢上阮淇。

还处于一厢情愿境况下的魔尊大人不但不知道殷勤些，还当着他这个娘家人的面‘偷懒’，蔺唯遵从私心默默在心底替风陵铃给他扣了二十分。

严格来说，他和阮淇的心理活动也算是公式错了结果对了的一种双向奔赴了。

蔺唯怕阮淇隐身跟在他身边作妖，以最快的速度把任务交代下去，然后拉着阮淇回了魔界。

此时的魔宫，庭院里只剩最后一个阵法，阮淇看见了才终于想起来他出门找蔺唯的目的，撇了撇嘴道：“我当时正想找你问问有没有法子能短时间内增强肉身实力呢？”

蔺唯轻叹一声，他本来是有很多办法的，但在炼了个最基础的补气丹都被天道意识警告后，他的办法就大多都无了。

他先是遵循原作试探道：“目前最简单的办法是我助你将混沌珠彻底炼化……”

“这不行。”阮淇竟想也没想就否定了这个提议：“混沌珠是主动出世认我为主，证明它是有灵智的，我不能这么做。”

面对这个答案，蔺唯莞尔一笑，他不意外阮淇会这么选，若非如此，原作里混沌珠也不会主动牺牲自己了。

“还有一个办法，就是我灌个一万年灵力到你体内，你炼化它。”

阮淇先是诧异，蔺唯才多大年纪，怎么会有这么多的灵力？不止生而知之，而且生而有之？

但就算是这样，他也不能欣然接受：“这怎么可以……”

“这是除了炼化混沌珠外唯一的办法！”蔺唯截断他拒绝的话：“这世上已经没有对你这个修为等级还能起太大作用的天材地宝了，要么牺牲混沌珠，要么接受我的灵力，你只能从中选一个。”

他先提混沌珠，也是吃准了阮淇肯定接受不了这个选项，比起将混沌珠彻底牺牲，用他的灵力虽然还是亏欠大了，但好歹还有机会可以偿还回去。

混沌珠要是被炼化，就要彻底消散于世间了，再怎么难，蔺唯也笃定阮淇会选后者。

“……你让我再想想。”

阮淇不信邪，他总觉得还会有其他办法，他不愿意让别人为他做这么大的牺牲，不管是混沌珠还是蔺唯。

“我要去藏书阁看看！”

蔺唯也不逼他立刻做决定，只道：“好，我跟你一起去。”

“嗯。”阮淇愁眉不展。

两人一前一后再一次上了藏书阁的最顶层，这回阮淇找书可方便许多了，直接把所有记载着快速提高本体实力的相关典籍都挪了出来一本一本翻。

蔺唯为了避嫌没看，这些都是魔族的修炼法门，他一个人族修仙者看不方便，尽管阮淇并不在意。

他本是断定阮淇绝对不可能找得到别的方法的，但大概是他也有知识不那么全面的时候，或者说他还是低估了魔族在提升实力这一方面的荤腥不忌，实力诠释了什么叫办法总比困难多！

凝神打坐闭目养神了一会儿，不知过了多久，他被一只手轻轻推醒。

睁开眼，阮淇在他面前，也不说话，满脸‘便宜你了’的羞耻为难混杂着被迫舍弃了什么的伤感遗憾。

后者表演痕迹略重。

不知道是不是错觉，蔺唯仿佛还从他眼中看到了一点一闪而过没藏好的…兴奋？

再低头一看，对方手里正拿着一本薄薄的册子。

蔺唯不明所以：“怎么了？”他没有冒昧地直接把册子接过来看，而是先问。

阮淇张了张嘴又闭上，好像有什么话难以启齿，看起来内心挣扎了好一会儿，脸红了又白白了又青的，最终咬咬牙，竟像是下定了什么决心似的，才直接把册子往他面前一递，让他自己看。

“你还真找到其他办法了？”蔺唯有些惊讶，他接过来，好奇地打开一看。

第一列魔文出现在眼前的时候，他还以为自己看错了。

他是能看懂魔文的，所以当‘双修’两个大字猝不及防闯入他眼帘的时候……

他的沉默，震耳欲聋。
