## ⛔ 1. QUY TẮC TỐI THƯỢNG: UNIVERSAL ZERO GOOGLE API KEY MANDATE

1. **AI Agent Tự Thân Dịch Thuật & Soát Lỗi Trực Tiếp:**
   - AI Agent tự đọc trực tiếp file nguyên tác thô (`chapters/ch_xxx/source.md`).
   - Tự phân tích ngữ cảnh, tâm lý tự ti hiểu lầm hài hước của Hebe và bản chất hai mặt (trước mặt cún con, sau lưng diệt thế) của Teyden.
   - Trực tiếp biên dịch sang tiếng Việt trau chuốt, giữ trọn sắc thái hài hước, văn phong mượt mà.
   - Trực tiếp ghi file kết quả (`translation.md`, `qc_report.md`, `final.md`) bằng công cụ ghi file chuẩn.
2. **CẤM TUYỆT ĐỐI Gọi Tool / Script Bên Ngoài Dùng Google API Key:**
   - Bảo toàn 100% quota/credit và triệt tiêu nguy cơ lỗi 429/503.

   - Số đoạn văn tiếng Việt trong `translation.md` phải khớp chính xác 1:1 với số đoạn văn trong `source.md`.

   - Bắt buộc có đúng 1 dòng trống (`\n\n`) ngăn cách giữa mọi đoạn trần thuật và lời thoại.
3. **Dấu Thoại Chuẩn Ngoặc Kép Cong `“...”`:**
   - Sử dụng ngoặc kép cong tiếng Việt `“...”` cho toàn bộ lời thoại.
